# 用户许可证

![](/docs-img/logos/gplv3.png)

____

本程序是自由软件，依据 [GNU 通用公共许可证 v3](gnu-gpl) 发布。该许可证保障你四项自由：

- **按你的意愿运行程序**的自由，可为任何目的使用；
- **研究程序如何工作并加以修改**的自由，让它按你的需求为你所用；
- **再分发副本**的自由，从而帮助你的同行动画师；
- **向他人分发你修改后版本副本**的自由。

## 这对用户意味着什么

第一项自由保障**你可以按自己的意愿使用本软件**，用于任何作品——无论是商业用途、个人用途还是非盈利用途。借助我们的工具制作出来的作品归你所有，你可以随意处置。

你不需要任何授权或许可合同。下载、安装、尽情享用吧！

请记住：**我们非常想看看你用我们的工具做出了什么**，所以[欢迎把你的作品发给我们](https://rainboxlab.org/about/contact/)！你也可以通过[捐赠](https://rainboxlab.org/about/donate/)来帮助这些自由工具的持续开发。

<Callout type="info">
    在影片致谢中提到本工具并非强制，但既然它是免费的，如果你这样做，我们会非常感激——这是一种说"谢谢"的好方式，不是吗！
</Callout>

## 这对开发者意味着什么

第二项自由**让你可以按需修改软件**。你可以在 [Github](https://github.com/RxLaboratory/) 获取源代码。

第三、四项自由让你可以**自行分享并分发我们的工具**，无论是否包含你的修改。然而，为了维持这四项自由，GNU 通用公共许可证要求**发布工具（包括你的修改）时必须采用兼容的许可证——同样保障这四项自由的许可证**。因此，**你既不能出售这些工具，也不能把源代码保密**。你还必须列出所分享和修改的自由软件的全部作者。简而言之，无论是否修改，这些工具都必须保持自由。

如果你把我们工具源代码的任何部分——哪怕只是一小段——纳入你自己的工具，那么你的工具也必须以自由软件许可证发布。**你不能出售任何包含自由许可证代码的软件。**
