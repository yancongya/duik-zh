# Duik Ángela（17）更新日志

本页列出自 Duik 上一个大版本（[Duik Bassel 16.2](duik-16-changelog)）以来的所有变更。

► [Duik 各小版本的详细变更列表见此处](https://github.com/RxLaboratory/Duik/releases)。

## 17.1

这个新版本的 Duik Ángela 引入了辅助色彩动画的重要功能，日后可能扩展为另一套专用工具集中的更多功能或工具。

- 为 Swink 在用于颜色时新增了控件和插值选项。
- 为 Interpolator 新增了颜色选项。现在你可以在插值时选择更合适的色彩空间，让关键帧之间的颜色更好（更鲜亮）。
- 新增向颜色属性添加列表（List）的功能。

还新增了性能改进与选项。

- 新增"轻量骨骼（Light Bones）"；可在骨骼设置面板或 OCO 创建元绑定选项中启用。
- 新增可选的栅格（PNG）控制器；相比形状图层大幅提升性能。该选项可在控制器设置面板中设置。
- 骨骼设置面板现在即使在骨骼已烘焙后也能编辑其颜色与不透明度。
- 烘焙表达式（Bake Expression）工具略有改进，在特定情况下能生成更接近原始曲线的关键帧插值。这是正在进行的关键帧与时间线相关工作的一部分。敬请期待！

此外，这个版本还带来了许多其他改进，让你的工作更轻松。

- 新增外推权重（Extrapolation weight），一个可动画化的百分比，用于调整 Looper/Interpolator 上的外推（例如开始和停止循环的循环 out/in）。
- 新增一个选项，默认不锁定空控制器的缩放（这样你可以用它们一次性快速缩放多个图层）。
- 新增在自动绑定中自动创建根控制器的选项。
- 为图钉（Pin）新增了不透明度控件。
- 重构了图钉设置面板，现在与其他设置面板保持一致。
- 允许 Kleaner 使用负的预备（anticipation）（用于模拟某种生锈卡顿的感觉，或动作启动时的迟疑）。
- Alt+点击 List 按钮，可自动向第二个槽位添加关键帧（并在时间线中按 `U` 快速显示它）。
- OCO 更新：OCO 现在使用 `OCO.config` 文件，在所有使用 OCO 的应用之间共享设置和 OCO 库，有点像 OpenColorIO 的配置文件。OCO 仍在大力开发中，未来几个月将在 After Effects、Blender 和 Krita 中加入许多新功能。
- "Bug report"（Bug 报告）按钮现在跳转到 rxlaboratory.org 上一个全新、更完善的表单，并预填了你的系统信息。

最后，还内置了新的 OCO 元绑定：

- 马（Horse）
- 熊（Bear）
- 狐猴（Lemur）
- 霸王龙（Tyrannosaurus）
- 蝎子（Scorpion）
- 鲸（Whale）
- 猴子（Monkey）

► [全部修复列表见此处](https://github.com/RxLaboratory/Duik/releases)。

## 17.0

### 新功能

#### （自动）绑定

<Callout type="info">
    与 Duik Bassel 相比，Duik Ángela 中工具的命名方式有一些变化。  
    • *Structures* 现在命名为 ***Bones***（单个）或 ***Armatures***（完整肢体）。  
    • 原来的 *Bones* 现在命名为 ***Pins***（图钉）。  
    本更新日志和全部文档现在都使用这些新命名。
</Callout>

- 新的***自动绑定***：
    - ***翅膀（Wings）***绑定现已支持。
    - ***头发（Hair）***绑定现已支持。
    - **_节肢动物腿_**绑定现已支持。
    - **_鱼（鳍与脊柱）_**绑定现已支持。
- **新的 _骨骼（Bones）_**：即以前的 Structures，骨骼已被重新设计，并为各类动物提供了新肢体（鱼及其鳍、蛇、翅膀……）。注意：以前版本 Duik 中的 *bones* 现在命名为 *Pins*（图钉）。
    - *骨骼*现在有可选的*包络*和*面条骨*。骨骼包络对于设计肢体、确保关节运作良好非常有用；配合骨骼面条骨，只需一次点击和少量设置，就能快速创建并动画化可定制肢体。
- 新的***控制器***形状：
    - 椎骨（Vertebrae）
    - 胸廓 / 躯干（Rib cage / Torso）
- 骨骼面板中的 ***Link art***（链接美术层）按钮会（尝试）自动把所有美术层设为对应骨骼的子级。

#### 约束

- ***连接器（Connector）***有了许多新能力：
    - 现在可以使用图层上的***音频***来控制属性。
    - 新增 *图层列表（Layer list）*模式，可快速把一堆图层连接到下拉菜单效果。
    - 界面已简化。
- 新的 IK/FK 类型：***Bézier FK***，*自动绑定*在脊柱和颈部绑定时会用到它。
- ***移动锚点（Move anchor point）***工具可以把选中图层的锚点移动到其边界或中心。它适用于像素图层和形状图层，也能利用蒙版。它还可以考虑自定义边距。该工具同时位于*链接与约束*面板和*动画*面板中。
- **_形态关键帧（Key Morph）_**：在其他软件中也称为 *Shape Keys*、*Pose Morph*、*Blend Shapes* 或 *Morphers*，现在借助 Duik 可在 After Effects 中使用，并能用*连接器*轻松连接到漂亮的控制器。
    - 可以用*连接器*把某个属性连接到一组形态关键帧。注意：主控属性必须使用关键帧（不能由表达式控制）。
- 界面调整：
    - **_动力学约束（Kinematics Constraints）_**按钮：快速为图层添加 IK 和 FK 约束。
    - **_父子约束（Parent Constraints）_**已归入同一按钮组。
    - **_变换约束（Transformation Constraints）_**已归入同一按钮组。
- **_2+1 图层 IK_** 是在 3 图层链上使用 IK 的新方式，对节肢动物和新的蹄行动物绑定方式很有用。

#### 自动化与表达式

- ***Kleaner*** 回来了，并且已被彻底重新设计。
    - 它现在使用直观的通用参数来控制整段动画（如幅度、重量、摩擦等），但你仍可以用更细致、更高级的参数进行微调。
    - 它现在能在不分离维度的情况下，正确处理空间属性上的缓动、预备和跟随。这种情况下，图层运动时只需使用漫游关键帧，停止时保持线性关键帧。Kleaner 会精确沿轨迹运动，同时处理好速度。
    - 会自动计算缓动，使运动尽可能平滑。如果你想在某个特定关键帧处停下，把它切换为*保持（maintain）*。
    - 重叠（以及软体模拟）大幅改进：动画更好更平滑，性能也略有提升。
    - 它现在还有（软）限制了！
- ***行走循环（Walk Cycle）***现在也是***奔跑循环（Run Cycle）***了。其控件和性能都大为改进。
- ***Swink*** 工具取代了以前的 *Swing* 和 *Blink* 工具。它让一个属性在两个值之间规律性切换，并提供高级选项来管理两者之间的频率和插值。
    - *Swink* 的频率可以被动画化。
- 当某个属性需要完全随机时，可使用 ***Random***（随机）自动化；例如 *Wiggle* 自动化过于平滑时。
- ***烘焙表达式（Bake expressions）***工具能把选中的表达式或整个项目的表达式烘焙成关键帧。它提供两种算法：一种是精确算法，每帧添加一个关键帧（或更少，取决于你可设置的精度系数）；另一种是*智能算法*，自动尽量少地添加关键帧，且生成的关键帧易于编辑。
- ***烘焙合成（Bake Composition）***工具会烘焙合成（或选中图层）中的所有表达式，并移除所有不可渲染图层（参考图层、空对象等）。如果某个可渲染图层被设为不可渲染图层的子级，其变换属性会被烘焙成关键帧。
- *自动化*和*工具*面板中的 ***Edit Expression***（编辑表达式）会在你喜欢的外部编辑器中打开选中的表达式，便于编辑，编辑完成后再把它们重新载入 After Effects 属性中。
- ***Expression tools（表达式工具）***：各种有用的工具，用于修复和处理表达式（在自动化面板工具栏中）。

#### 动画

- 新的**_非线性动画（NLA）_**工具取代了以前的 *Animation Blender* 工具。它像在 *Adobe Premiere* 这类非线性视频编辑器中剪辑视频片段一样编辑动画，非常出色且极其简单。
- 动画面板中有一个 ***补间（Tweening）***区，在你先使用保持关键帧、再转曲线时（无论是否用 *Kleaner*）帮你补间动画。包含以下新工具：
    - ***Tween Slider（补间滑块）***：根据上一个姿势与下一个姿势之间的比例，在当前时间添加一个新的中间帧。
    - ***Split Keyframes（拆分关键帧）***：把选中的关键帧拆分成成对的同值关键帧（把姿势冻结一段预定时间）。
    - ***Freeze pose（冻结姿势）***：把上一个（或下一个）姿势冻结到当前时间（把上一个或下一个关键帧复制到当前时间）。
    - ***Sync Keyframes（同步关键帧）***把所有选中的关键帧移动到当前时间。如果同一属性中选中了多个关键帧，它们会整体偏移到当前时间，同时保留动画。
    - ***Snap Keyframes（吸附关键帧）***：如果关键帧落在两帧之间（例如改变动画时长或合帧率时会出现这种情况），把它们吸附到实际帧上。
- ***Sequencer（序列器）***在时间上排布你的图层或关键帧。
- 新的**_Interpolator（插值器）_**工具（动画面板）。*Interpolator* 是一个帮你……插值关键帧的工具。它有点像 *Kleaner*，但是在更底层，你可以真正选择并调整动画的插值方式，面向更高级的用户。
    - 它包含用于循环入/出的*外推*方法，并有不同模式：恒定（constant）、继续（continue）、往返（ping pong）、循环（cycle）、弹跳（bounce）、跟随（follow-through）。
    - 当外推被动画化时（例如停止一个循环），属性现在会停留在正确的值。
    - 如果属性保持静止，它能在关键帧之间外推运动（循环）。
- 借助新的**_动画库（Animation library）_**（动画面板），快速保存、导出、导入并应用动画。

#### 工具

- ***DuCop***（Duduf Comp Parameters）现已包含在 Duik 中（工具/合成面板）。它让你可以更改所有选中合成（包括其预合成）的合成设置。如果合成时长和尺寸改变，它还会相应调整那些应当匹配新合成时长和尺寸的图层。
- 使用 ***Crop precompositions（裁剪预合成）***来……裁剪预合成。该工具利用预合成图层上的蒙版来裁剪源合成：只需在图层上快速画一个蒙版，然后点击按钮裁剪合成，而不会移动任何使用同一源合成的图层。
- **_图层管理器（Layer Manager）_**将帮助你（重）命名图层，并为绑定和图层分组设置有用的标记。
- ***注释面板（Note panel）***现在还能保存特定于合成或项目的注释。这些注释保存在项目文件中。
- ***脚本库（Script library）***帮你整理所有脚本。在那里，你可以轻松访问、编辑并启动已安装的脚本、可停靠面板，或任何其他独立脚本。
- ***脚本编辑器（Script editor）***是一个基础脚本，让你编辑并运行简单脚本。但即使它很基础，也包含了整个 Duik API，让你用几行简单代码就能轻松调用 Duik 的高级功能。

#### 杂项

- **全新用户界面**：伴随着彻底的代码重构，*Duik* 经历了完整的界面重设计。性能（加载时间）已改善，*Duik* 现在更贴合 After Effects 的界面，更低调，让你专注于工作。
- **彻底的代码重构**：Duik 更易维护，代码组织更清晰，性能已提升……
- 面板底部有一个进度条，显示当前的资金状况……
- 我们终于放弃了对 *After Effects CS6* 的支持，抱歉，为太少的用户保持兼容性代价太大。*CS6*（*v11.0.2*）要追溯到 2012 年 10 月，是时候升级了！*Duik* 现在应能在从 *After Effects CC*（*v12.0*，2013 年 7 月）起的所有 After Effects 版本上运行。

### 改进

#### （自动）绑定

- 几乎所有工具和表达式的性能都已改进。
- *腿部*：
    - *脚掌翻转（Foot Roll）*的性能通过更简单的绑定得到（大幅）改进。
    - *蹄行腿*绑定已修改，更贴近你所食用动物（牛、可爱的小羊、马……）的真实解剖结构。
- *脊柱自动绑定*已调整，以更好处理某些特殊情况，并整体改善对脊柱和躯干的控制。
- *尾巴*以及所有*带重叠的 FK*现在可以拉伸了！
- *显示/隐藏* *骨骼*和*控制器*：`[Alt] + [点击]` 仅显示/隐藏未选中的图层。
- *IK/FK*：
    - *3 图层 IK* 已从 *Duik* 中移除，因为没人用它，而且可以轻易用更好的 2+1 或 1+2 IK 替代。
    - 为 2 图层和 3 图层 IK 新增了*权重*滑块，以便在 IK 与 FK 之间渐进过渡（这在新的*非线性动画*和*动画库*中可能很有用）。
    - 从 IK 效果中移除了*高级 / 完整旋转限制*选项。
    - *单图层 IK* 现在有可选的限制，并带一个柔和度参数。
    - *双图层 IK* 的两侧现在可以渐进切换，并且有一个 *auto-swing* 选项可以自动反转关节。
- *骨骼*和*控制器*的尺寸现在会随合成尺寸自适应（如果它们尚未烘焙）。

#### 约束

- *连接器*现在可以连接速度或速率。
- 形状上的*图钉*：在顶点图层的效果中新增了"锁定切线（Lock tangent）"按钮。
- *父子约束*的性能已大幅改进。注意：权重属性中的表达式可能无法正常工作，你可能需要把它们烘焙成关键帧（例如使用 Duik 新的*烘焙表达式*工具）。
- *定位器*（被*跨合成父子约束*使用）现在创建在图层堆栈的底部。
- *路径约束*：`[Alt] + [点击]` 把图层移动到路径的第一个点。
- *列表（List）*现在可以简单复制来获得更多轨道。
- *属性信息（Property Info）*现在显示关键帧信息。

#### 自动化与表达式

- *Wiggle（抖动）*：
    - *Wiggle* 现在可以为每个受控图层可选地使用不同的种子。
    - *Wiggle* 的频率现在可以被动画化。
    - 初始随机种子的选取更合理。
- *Effector* 现在也支持*自定义形状*了！（除圆形和直线之外）。
- *Randomizer（随机化器）*现在能生成沿*高斯钟形*函数分布的随机值，结果更自然。
- *运动轨迹（Motion Trail）*参数已改进，现在能使用 After Effects >= 17.1 的锥形参数。
- *Wheel（轮子）*自动化新增了 *Straight（直线）*选项，用于沿非水平直线运动的轮子，相比 *Curved（曲线）*选项在这种特定情况下性能更好。
- *Looper（循环器）*现在使用新的 *Interpolator* 工具。
- 把 *Separate dimensions（分离维度）*重命名为 *Split values（拆分值）*。

#### 动画

- *复制动画*：`[Alt] + [点击]` 剪切关键帧。
- *IK/FK 切换*工具现在能更好地处理同时包含单图层和双图层 IK 的控制器（如手臂及其肩部）。

#### 摄像机

- *2D 多平面摄像机（2D Multiplane Camera）*工具现在组织得更好，在所有层级之上有一个单独的摄像机控制器。
- *摄像机绑定（Camera rig）*现在包含了高级行为，就像 *2D 多平面摄像机*早已具备的那样。
- *摄像机绑定*和 *2D 多平面摄像机*现在都会自动处理运动插值，实现完美平滑的摄像机运动。

#### 工具

- 现在也可以在效果名称中*查找和替换*了。

#### 杂项

- *重命名*：重命名木偶图钉时，只需选中单个图层即可重命名其上找到的所有木偶图钉，不必再逐个选择图钉。
- *自检（Sanity tests）*：
    - *自检*已改进，运行更高效。现在会检查 *After Effects* 的连续运行时长，因为 *After Effects* 存在内存泄漏，需要每隔几小时重启一次，以保持内存占用和性能最佳。
    - 性能改进。当项目过大时，某些测试可能会暂停；它们仍可手动运行。
- *Scriptify Expression（脚本化表达式）*工具现在会根据属性名创建一个变量，并转换为驼峰命名（camelCase）。

### 修复

- 修复了 IK 在被拉伸时偶尔出现的闪烁问题。
- *Scale Z-Link* 现在在摄像机锁定时也能正常工作。
- *摄像机绑定*工具不再因单点摄像机而失败，而是显示一个友好提示。
- *复制 / 粘贴动画*和*动画库*现在能处理文字关键帧。
- *复制 / 粘贴动画*现在能正确选中缺失的图层。
- *编辑模式*现在能与已锁定的子图层正常配合。
- *提取控制器*在 *After Effects* > 22.0 上现在更快、更可靠。
- *图钉*现在与 3D 图层配合得更好。
