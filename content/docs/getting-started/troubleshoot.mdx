# 故障排除

如果 Duik 出了问题，这里有一些技巧，帮助你自己解决。

## 1 - 先查常见问题解答（FAQ），看有没有答案。

► [**点此阅读 FAQ**](../faq)。

如果 **FAQ 里没有答案**，而你的问题是**报错/崩溃/bug，请继续下一步**。

**如果没有出现任何错误**，没有崩溃、没有 bug，请阅读本文档确认你正确使用了 Duik，然后**来[和我们聊聊](http://chat.rxlab.info)**[^1]，以便我们帮助你。

## 2 - 使用 DuSI 获取系统信息并清理/重装 Duik。

我们提供了一个名为 [*DuSI*](https://rxlaboratory.org/tools/dusi/) 的脚本，用于清理 RxLaboratory 为 After Effects 开发的所有工具，并可以在需要更多支持时收集有用的系统信息。

脚本在你安装 Duik 时下载的 *Zip* 压缩包的 `tools` 子文件夹中。也可以[点此下载](https://rxlaboratory.org/tools/dusi/)。

无需安装，在 After Effects 中通过 `File/Scripts/Run script file...` 菜单直接运行即可。

会显示这个面板：

![](/docs-img/dusi/dusi.png)

1. 点击 *Get System Information* 按钮并保存文件。把文件放在手边，之后若需更多支持可能会用到。
2. 点击 *Fix / Uninstall* 按钮。

大多数时候，这个简单流程就能修复你可能在 After Effects 中使用的所有 RxLab. 工具。重新启动 Duik，检查是否正常。

如果 Duik 仍然不正常，请继续下一步。

## 3 - 以调试模式运行 Duik

1. [进入 *Duik* 设置](../guide/settings)，启用 *Dev and Debug mode*
2. 重启 *Duik*
3. 尝试重现问题，复制或截图 *After Effects* 或 *Duik* 显示的任何错误。
4. 把默认文档目录下 *Duik* 子文件夹中的调试日志复制到安全位置，之后附在请求或 bug 报告中。

## 4 - 提交 bug 报告

1. 前往 [*rxlaboratory.org/issues* 上的 **issues** 报告表单](https://rxlaboratory.org/issues)。也可以点击 Duik 面板底部的 <img src="/docs-img/duik/icons/bug.svg" style={{width: '20px'}}/> 按钮快速打开该页面。
2. 尽量填写**全部细节**：问题具体是什么、发生时你在做什么、显示了什么错误、问题的截图或录屏……
3. **附上**第 *2* 步获取的系统信息报告。  
   **这是必填项**。可以复制粘贴内容到表单中。
4. **附上**第 *3* 步获取的调试日志。  
   **这是必填项**。可以复制粘贴内容到表单中。
6. **耐心等待**。我们会尽快查看你的报告。

## 5 - 联系我们

欢迎[来和我们聊聊](http://chat.rxlab.info)[^1]，方便直接讨论问题。这是唯一会得到回复的渠道，我们在其它任何平台都不提供支持。

[^1]: 联系我们的链接：[chat.rxlab.info](http://chat.rxlab.info)
