# <img src="/docs-img/duik/icons/library.svg" style={{width: '1em'}}/> 动画库

<Video src="https://rxlaboratory.org/wp-content/uploads/rx-videos/Duik17_J07_AnimLib__EN_720.mp4" caption="本视频是 Duik Ángela 官方完整视频课程的一部分" />

动画库是一种快捷方式，用来存储、管理和共享可复用的动画。

它既是 Duik 里的一个面板，也是你磁盘上的一个文件夹，这样就可以方便地同步[^sync]和共享。

[^sync]: 用 *DropBox*、*OneDrive* 等工具可以很容易地在多台电脑之间同步文件。但我们强烈推荐使用免费开源的 [Syncthing](https://syncthing.net/)：[syncthing.net](https://syncthing.net/)

## 面板

![](/docs-img/duik/animation/anim-library.png)

你可以用面板顶部的输入框快速搜索动画、在分类间导航。

1. **选择**要接收动画的图层。
2. 在列表中**选择一个动画**。
3. 点击 ![](/docs-img/duik/icons/check.svg) ***应用*** 按钮，把动画应用到当前图层的当前时间点。  
    你可以 `[Shift] + [点击]` 该按钮来访问更多选项。

你可以点击 ![](/docs-img/duik/icons/folder.svg) 文件夹图标，打开库存放的文件夹；或者 `[Alt] + [点击]` 它，让 Duik 使用另一个文件夹。如果新文件夹里已经有一个库，它会被自动加载；这是在同一系统上保留多个库的简便方法。  
默认情况下，库位于你文档文件夹下的 `Duik` 子文件夹，设置、笔记和翻译也默认存在这里。

接下来的几个按钮，可以改变面板中条目的排序方式；如果你手动添加了新文件，或列表里缺了什么，还可以刷新库。

<Callout type="info">
    目前（2024 年）动画是*原样*应用的，因此当把动画从一个角色转移到另一个比例不同的角色时，需要手动调整位置和其他空间数值。不过其他属性应该都能正常工作。不过这即将改变：我们正在想办法自动让动画适配接收它的角色——同时存储原角色的比例，以便在应用到新角色（或道具）之前先套用一个比例。
</Callout>

### 选项

![](/docs-img/duik/animation/anim-library-options.png)

你可以选择把所有可用数值应用到所有属性，或者只应用那些被动画过的数值（带关键帧的）。

你还可以通过勾选图标，选择使用或忽略哪类属性：

- ![](/docs-img/duik/icons/move.svg) 图层位置
- ![](/docs-img/duik/icons/rotate.svg) 图层旋转
- ![](/docs-img/duik/icons/scale.svg) 图层缩放
- ![](/docs-img/duik/icons/opacity_l.svg) 图层不透明度
- ![](/docs-img/duik/icons/mask.svg) 蒙版
- ![](/docs-img/duik/icons/fx.svg) 效果
- ![](/docs-img/duik/icons/props.svg) 所有属性

新数值可以替换（***absolute（绝对）***）当前数值，也可以叠加（***offset（偏移）***）到当前数值上；你还可以选择在时间上**反转**关键帧。

### 编辑库

#### ![](/docs-img/duik/icons/add.svg) 添加

点击 ![](/docs-img/duik/icons/add.svg) *添加* 按钮，可在当前库分类中添加一个新分类，或从当前选中的图层添加一个新动画。

添加新动画时，你可以选择自动把所有表达式烘焙成关键帧。若需要烘焙过程的更多选项，可以事先改用 [烘焙表达式](../automation/tools/bake)&nbsp;[^bake] 工具。

[^bake]: *参见* [自动化与表达式](../automation) / 工具 / [烘焙表达式](../automation/tools/bake)。

Duik 会渲染合成的当前帧，用作缩略图。

#### ![](/docs-img/duik/icons/edit.svg) 编辑

选中一个分类，点击 ![](/docs-img/duik/icons/edit.svg) *编辑* 按钮，可修改它的名字。

选中一个动画，点击 ![](/docs-img/duik/icons/edit.svg) *编辑* 按钮，可更换它的缩略图、名字，把它替换成另一个动画，或把它加入收藏。

![](/docs-img/duik/animation/anim-library-edit.png)

<Callout type="info">
    更新缩略图时，Duik 会使用当前活动合成的当前帧——它可以是任何合成，不一定是包含原动画的那个。
</Callout>

#### ![](/docs-img/duik/icons/remove.svg) 移除

选中一个分类或一个动画，点击 ![](/docs-img/duik/icons/remove.svg) *移除* 按钮即可删除。

## 文件夹

动画库所在文件夹的层级结构，与面板中分类的层级一致。在这个文件夹里改动文件及其位置，实际上也会在库面板里同步改动。

一些元数据（比如收藏和历史记录）存放在主文件夹根目录的 `Duik_animation_library.json` 文件里。

<Callout type="info">
    目前（2023 年）动画使用 `duio` 格式存储，这是 Duik 和 [DuIO](https://rxlaboratory.org/tools/duio)&nbsp;[^duio] 专用的格式；但这很快就会改变——RxLaboratory 正在开发的 ***OKA***，即 ***Open Keyframe Animation（开放关键帧动画）*** 格式即将推出。
</Callout>

[^duio]: *DuIO* 是一套用于在 After Effects 中导出和导入内容的工具。可在 [rxlaboratory.org/tools/duio](https://rxlaboratory.org/tools/duio) 获取。

缩略图以 `.png` 文件存储，文件名与动画的 `.duio` 文件同名。
