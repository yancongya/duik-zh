# 空间插值

![](/docs-img/duik/animation/spatial-interpolation.png)

这里有几个按钮，帮你快速切换所选关键帧的空间插值类型。

![](/docs-img/duik/icons/autorig.svg) ***修复（Fix）*** 按钮会自动修复所选关键帧上的空间插值问题。这种问题通常发生在：你复制了一个关键帧、稍后又粘贴它，而被复制的关键帧用的不是线性空间插值。这时，由于 Bézier 空间插值，两个关键帧之间可能会出现一段错误的运动。把这两个关键帧设为正确的线性插值即可修复。*修复*按钮就是通过检测两个相邻关键帧数值是否相同来做到这一点的。

1. **选择**空间属性上的关键帧。
2. 点击 ![](/docs-img/duik/icons/autorig.svg) ***修复*** 按钮。  
    数值相同的相邻关键帧之间（且仅此情况）的所有 Bézier 插值都会被设为线性。
