# <img src="/docs-img/duik/icons/copy.svg" style={{width: '1em'}}/> <img src="/docs-img/duik/icons/paste.svg" style={{width: '1em'}}/> 复制、剪切与粘贴动画

<Video src="https://rxlaboratory.org/wp-content/uploads/rx-videos/Duik17_J01_AnimTools01__EN_720.mp4" caption="本视频是 Duik Ángela 官方完整视频课程的一部分" />

你可以一次性复制或剪切多个图层的动画，并在不同合成之间粘贴。

- **选择**一些关键帧
- 点击 ![](/docs-img/duik/icons/copy.svg) ***复制动画*** 按钮。  
    - `[Alt] + [点击]` 可**剪切**关键帧，而不是复制。
- **选择目标**图层，并把**时间指示器**移到你想粘贴动画的时间点。
- 点击 ![](/docs-img/duik/icons/paste.svg) ***粘贴动画*** 按钮。  
    - `[Alt] + [点击]` 反转动画方向。
    - `[Ctrl] + [点击]` 以当前数值为基准偏移动画（而不是替换当前数值）。

粘贴动画时还有一些其他选项，`[Shift] + [点击]` ![](/docs-img/duik/icons/paste.svg) *粘贴动画* 按钮即可访问。
