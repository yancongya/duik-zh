# <img src="/docs-img/duik/icons/motion_trail.svg" style={{width: '1em'}}/> 运动轨迹

▷ *参见[自动化](../../automation) / [运动轨迹](../../automation/motion-trail)*。

<Callout type="success">
    *运动轨迹* 对动画师非常有用：它可以显示任意图层的真实运动轨迹（比如用 IK 给腿部做动画时的膝盖），不像 After Effects 自带的轨迹会随父图层一起变换……
</Callout>

<Callout type="success">
    只要把运动轨迹图层设为*参考图层*，就能确保它最终不会被渲染出来。
</Callout>
