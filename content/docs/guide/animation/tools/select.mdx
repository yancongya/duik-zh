# <img src="/docs-img/duik/icons/select.svg" style={{width: '1em'}}/> 选择关键帧

<Video src="https://rxlaboratory.org/wp-content/uploads/rx-videos/Duik17_J01_AnimTools01__EN_720.mp4" caption="本视频是 Duik Ángela 官方完整视频课程的一部分" />

*选择关键帧* 是一个非常实用的工具，可以在时间轴上快速同时选中大量关键帧。

你可以 `[Shift] + [点击]` 按钮来访问一些选项。

![](/docs-img/duik/animation/select-keys.png)

- 你可以选择特定时间点上的关键帧，或某个时间范围内的关键帧。

- 时间可以是当前时间指示器的时间，也可以是某个指定时间；时间范围可以是工作区域，也可以是某个指定范围。  
    要设置指定时间和时间范围，可以点击吸管，从播放头或工作区域拾取当前数值。

- 你可以使用筛选条件，只选择特定类型的关键帧，或只选择特定图层上的关键帧。
