# <img src="/docs-img/duik/icons/ik_fk_switch.svg" style={{width: '1em'}}/> IK / FK 切换

<Video src="https://rxlaboratory.org/wp-content/uploads/rx-videos/Duik17_J03_AnimTools02__EN_720.mp4" caption="本视频是 Duik Ángela 官方完整视频课程的一部分" />

*IK/FK 切换* 能让你在动画过程中轻松地在反向动力学（IK）与正向动力学（FK）之间切换，前提是这些图层已经用 Duik 绑定。

1. **选择**用 Duik 创建的 IK 的控制器
2. 点击 ![](/docs-img/duik/icons/ik_fk_switch.svg) ***IK / FK 切换*** 按钮。  
    Duik 会自动判断需要切换到 IK 还是 FK，并在当前时间设置必要的关键帧来完成切换。

切换分两步进行：

1. Duik 会把 FK 吸附到 IK，或反过来（取决于切换方向），并添加关键帧以保持当前帧的数值不变。
2. Duik 真正在 IK 与 FK 之间切换，并在当前时间添加关键帧。

你可以 `[Shift] + [点击]` ![](/docs-img/duik/icons/ik_fk_switch.svg) IK / FK 切换按钮来访问吸附工具。

![](/docs-img/duik/animation/ikfk.png)

在这里你可以手动把 FK 数值吸附到 IK，或反过来，而不真正切换 IK/FK——如果你确实需要这样做的话。
