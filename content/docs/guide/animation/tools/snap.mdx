# <img src="/docs-img/duik/icons/snap.svg" style={{width: '1em'}}/> 吸附关键帧

<Video src="https://rxlaboratory.org/wp-content/uploads/rx-videos/Duik17_J03_AnimTools02__EN_720.mp4" caption="本视频是 Duik Ángela 官方完整视频课程的一部分" />

很多时候，当你重新调整动画时间后，一些关键帧会落在合成的实际帧之间。修复方法是：**选中所有关键帧**，然后点击 ![](/docs-img/duik/icons/snap.svg) ***吸附*** 按钮；这会把所有错位的关键帧移到实际帧上。
