# ![](/docs-img/duik/icons/sequencer.svg) Sequence

<Video src="https://rxlaboratory.org/wp-content/uploads/rx-videos/Duik17_J09_Sequence__EN_720.mp4" caption={"This video is part of [__the official comprehensive video course about Duik Ángela__](https://rxlaboratory.org/product/the-official-comprehensive-video-course-about-duik-angela/)"} />

The *Sequence* tool distributes layers or keyframes in time.

![](/docs-img/duik/animation/sequence-linear.png)

1. **Select** some layers or keyframes
2. Click the ![](/docs-img/duik/icons/sequencer.svg) ***Sequence*** button.  
    `[Shift] + [Click]` the button to access some options

![](/docs-img/duik/animation/sequence.png)

You can sequence either the selected **layers** or the selected **keyframes**.

When sequencing the layers, you can choose to either **move** them (***Times***) or **cut** them (***In points*** or ***Out points***).

There are several interpolation[*](../../misc/glossary) algorithms available, which define the shape of the sequenced layers or keyframes.

- **Linear**

![](/docs-img/duik/animation/sequence-linear.png)

- **Ease** - Sigmoid (logistic)

![](/docs-img/duik/animation/sequence-sigmoid.png)

- **Natural** - Bell (gaussian)

![](/docs-img/duik/animation/sequence-gaussian.png)

- **Ease In** (logarithmic)

![](/docs-img/duik/animation/sequence-easin.png)

- **Ease Out** (exponential)

![](/docs-img/duik/animation/sequence-easout.png)

For all but the *linear* interpolations, you can adjust the shape with the ***rate*** slider.

Of course, you can also set the duration of the sequence, in frames.
