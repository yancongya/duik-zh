# <img src="/docs-img/duik/icons/sequencer.svg" style={{width: '1em'}}/> 序列

<Video src="https://rxlaboratory.org/wp-content/uploads/rx-videos/Duik17_J09_Sequence__EN_720.mp4" caption="本视频是 Duik Ángela 官方完整视频课程的一部分" />

*序列（Sequence）*工具用于在时间上分布图层或关键帧。

![](/docs-img/duik/animation/sequence-linear.png)

1. **选择**一些图层或关键帧。
2. 点击 ![](/docs-img/duik/icons/sequencer.svg) ***序列*** 按钮。  
    `[Shift] + [点击]` 该按钮可访问一些选项。

![](/docs-img/duik/animation/sequence.png)

你可以对选中的**图层**或选中的**关键帧**做序列排列。

排列图层时，你可以选择是**移动**它们（***Times***）还是**剪切**它们（***In points*** 或 ***Out points***）。

有若干插值[*](../../misc/glossary)算法可用，它们决定排列后图层或关键帧的形状。

- **线性（Linear）**

![](/docs-img/duik/animation/sequence-linear.png)

- **缓动（Ease）** —— S 形（逻辑斯蒂 logistic）

![](/docs-img/duik/animation/sequence-sigmoid.png)

- **自然（Natural）** —— 钟形（高斯 gaussian）

![](/docs-img/duik/animation/sequence-gaussian.png)

- **缓入（Ease In）**（对数 logarithmic）

![](/docs-img/duik/animation/sequence-easin.png)

- **缓出（Ease Out）**（指数 exponential）

![](/docs-img/duik/animation/sequence-easout.png)

对于除*线性*之外的所有插值，你都可以用 ***rate（速率）*** 滑块调整形状。

当然，你也可以设置序列的时长（以帧计）。
