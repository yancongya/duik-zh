# <img src="/docs-img/duik/icons/animation.svg" style={{width: '1em'}}/> 动画

![](/docs-img/illustration/emilecohl.svg)  
*《Un drame》（一场戏剧），  
Émile Cohl，1908 年   
公有领域。*

角色和道具绑定好之后，再搭好用得上的程序化动画和自动化，接下来就轮到真正动起来、和关键帧打交道了。  
在操作关键帧、插值和动画方面，After Effects 略显局限，尤其是和 3D 软件相比。Duik 用大量动画与插值[*](../../misc/glossary)工具补上了这块短板。

## 动画面板

![](/docs-img/duik/animation/animation-panel.png)

顶部工具栏里的工具，是你做动画时可能会用到的快捷工具。

面板第二部分的主要工具，是 Duik 中全部动画工具，让你在跟关键帧较劲时随手可取。
