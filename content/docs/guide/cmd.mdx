# <img src="/docs-img/duik/icons/cmd.svg" style={{width: '1em'}}/> 命令行

Duik 的命令行面板（Command panel）为 Duik 提供了一个命令行界面（CLI）。

![](/docs-img/illustration/CPM_2-2.jpg)  
*CP/M 2.2 截图，运行于一台 Sanco 8001 电脑，  
Michael Specht，  
[CC-BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/deed.en)。*

这是一个功能强大的面板：你几乎可以用它调用 Duik 的每一项功能！借助强大的自动补全，只需输入几个字符，就能快速使用所有工具。

![](/docs-img/duik/cmd.png)

在第一个输入框中输入你想找的分类或命令名称，即可快速访问。一开始输入，Duik 就会在下方列表中过滤出可用的分类或命令；按 `[空格]` 快速确认并进入过滤列表中的第一个分类，按 `[回车]` 运行对应的命令。输入 `..` 可以回到上一级分类，这样就能非常快地在 Duik 的所有命令和功能之间导航。

你也可以更简单地把列表当作一个库，`[双击]` 其中的条目来导航。

这个面板实际上可以替代整个 Duik 界面；它还作为一个非常轻量的[独立面板](../getting-started/first-look#individual-panels)[^individual]提供，名为 `Duik Cmd.jsx`。

[^individual]: *参见* 简介（Introduction）/ [快速上手](../getting-started/first-look) / [独立面板](../getting-started/first-look#individual-panels)。
