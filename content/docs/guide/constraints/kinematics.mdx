# <img src="/docs-img/duik/icons/ik.svg" style={{width: '1em'}}/> 反向动力学与正向动力学（IK / FK）

绑定与动画中的*动力学*[*](../../misc/glossary)，描述了控制和动画化肢体关节（也就是动力学链[*](../../misc/glossary)）旋转与位置的几种方法。

![](/docs-img/illustration/Ambroise_Pare_prosthetics_mechanical_arm_Wellcome_L0043497.png)  
*机械臂插图；Instrumenta chyrurgiae et icones anathomicae  
Ambroise Paré，1564  
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/deed.en)，[Wellcome Library](http://wellcomeimages.org/)，伦敦。*

通常，给任何肢体做最基础的绑定，就是把图层从末端（子级，例如手或脚）到根部（父级，例如肩或髋）父子化在一起。  
在这个简单情形下，这叫做***正向动力学（FK）***[*](../../misc/glossary)：你只需动画化从根到端每个关节的旋转，就能动画化整条肢体。  
这是动画化肢体最简单的方式，因为旋转是简单数值，每个关节只有一个值要动。只要末端（例如手或脚）不与其他运动方式不同（或干脆静止，比如脚踩地面）的东西发生交互和约束，它就一直有效。

但如果你需要约束肢体末端，或者在动画化根部时让末端保持静止（例如移动髋部时让脚仍然踩在地上），那就需要另一种方法——你可以用位置而不是旋转来动画化肢体的两端。这就是***反向动力学（IK）***[*](../../misc/glossary)，因为与 FK 相反，你要动画化肢体末端，然后位置值会按相反顺序、从末端到根部自动转换成旋转值。这让做出漂亮动画稍微难一点，因为你得留意肢体末端的轨迹，还要处理多维、比简单旋转更复杂的位置属性。

![](/docs-img/examples/IK.gif)  
*Claude Autret "Jissse"  
保留所有权利*

<Callout type="info">
    用 IK 做动画时，你既要像用 FK 做旋转那样设置位置关键帧的值及其时间插值[*](../../misc/glossary)，还得管理空间插值，确保肢体始终沿曲线轨迹运动（而不是直线）[^1]。
</Callout>

借助 Duik（和自动绑定），你可以把肢体绑成能随时根据动画当下的需要在 IK 与 FK 之间切换的形式。还有一些特殊的 IK 类型，用来简化较长肢体的动画，比如马腿、蚂蚁和螃蟹腿，甚至发束、尾巴、脊柱和长脖子。

## IK 与 FK 的创建

用不同类型的 Duik IK 和 FK 控制来绑定 After Effects 图层，有两种方式：

- 使用 Duik [骨骼](../bones)和[自动绑定](../bones/autorig)&nbsp;[^2]。
- 使用 *![](/docs-img/duik/icons/ik.svg) 动力学（Kinematics）*菜单，位于 *![](/docs-img/duik/icons/constraints.svg) 约束（Constraints）*面板中。用这种方式，你可以绑定任意类型的图层。

两种方式都允许你自定义 Duik 创建的 IK/FK 控制类型。

Duik 会根据 IK/FK 的类型创建一个或多个控制器图层，并在这些控制器上加一些效果，用来调整设置、对肢体做更精确的控制。

### 使用自动绑定

虽然自动绑定是个聪明的工具，无论你选什么图层它都会尽力而为，但最好只把它和 Duik 骨骼一起使用。

1. 选中你要绑定的骨骼图层。
2. 点击 *![](/docs-img/duik/icons/autorig.svg) 自动绑定* 按钮。这个按钮在 ![](/docs-img/duik/icons/oco.svg) *元绑定（Meta-Rig）*、![](/docs-img/duik/icons/bone.svg) *骨骼（Bones）*和 ![](/docs-img/duik/icons/constraints.svg) *链接与约束*面板中都有。

使用自定义骨骼时，以及处理尾巴、发束等其他特定长链时，你可以选择要使用的 FK 或 IK 控制类型。详见 *[骨骼与自动绑定 / 自动绑定](../bones/autorig)*一节。

### 使用动力学菜单

这种方式适用于所有图层。

1. 把图层从肢体末端（子级）到根部（父级）父子化在一起。
2. 如果你想使用自定义控制器，创建一个控制器图层[^3]。这是可选的；如果还没有可用的控制器，Duik 会替你创建一个。
3. 点击 ![](/docs-img/duik/icons/ik.svg) *动力学*菜单，然后点击你想使用的 IK 或 FK 控制类型。

![](/docs-img/duik/constraints/kinematics-menu.png)  
*提供多种 IK 和 FK 控制类型。*

这个菜单显示不同类型的 IK 和 FK 控制：

- **标准 IK/FK**  
    适用于单层、两层和三层链；三层链还有一些专门选项，详见下文。
- **Bézier IK**  
    虽然 Bézier IK 可用于任意图层链，但它对超过两层的链尤其有用。
- **带重叠动画的 FK**  
    对于你确定不需要 IK 的链，这是一种非常方便的纯 FK 控制。
- **Bézier FK**  
    这是一种基于 Bézier IK 控制的特殊控制，但绑定方式让你可以动画化旋转，而不是 Bézier IK 控制器的位置。

## 标准 IK/FK

标准 IK 和 FK 控制可用于一到三层的链（加上末端，比如手或脚）。它几乎可用于所有种类的腿和手臂。

<Video src="https://rxlaboratory.org/wp-content/uploads/rx-videos/Duik17_E04_Arm__EN_720.mp4" caption="本视频是 Duik Ángela 官方完整视频课程的一部分" />

### 单层链

在单个图层上使用时，被绑定图层会自动旋转，始终指向它的控制器。

![](/docs-img/duik/constraints/1l-ik_00000.png)

用这种 IK/FK，你既可以动画化控制器的位置和被绑定图层（或其父级）的位置，也可以动画化图层自身的旋转。这意味着你可以按意愿用 IK 或 FK 来动画化。  
如果绑定图层时存在末端图层（例如手、脚……），它可以通过控制器的旋转属性来旋转。

控制器上的效果让你可以自定义这个控制。

![](/docs-img/duik/constraints/1l-ik-effect.png)

- ***IK***：必要时你可以禁用 IK；它可以被做成动画。
- ***权重（Weight）***：如果你把它设为低于 `100 %` 的值，图层旋转的角度就会小于指向控制器所需的角度。  
    举例来说，Duik 就是这样绑定“移动手时肩部自动旋转”的。
- ***FK***：用这个值来控制被绑定图层的旋转。  
    放在这里只是为了方便，因为你也可以直接动画化图层实际的旋转。
- ***限制（Limits）***定义图层旋转的边界。  
    例如把肩部旋转限制在其自然范围内会很有用。为帮助你定义这些限制，你可以用参考线把它们可视化。
- ***高级（Advanced）***：  
    - ***继承父级旋转（Inherit parent rotation）***：勾选后，图层会随其父级旋转。  
        取消勾选则确保无论祖先如何旋转，图层始终保持自己的朝向。
    - ***完整旋转限制（Full rotation limit）***：当你绕着移动控制器到某个点时，图层的旋转值会出现一次 360° 跳变。  
        勾选此项可把这个跳变设到另一侧，即上方 180° 处。
- ***数据（Data）***区段包含 Duik 计算动力学所需的一些数据。
- ***显示（Display）***：  
    - ***绘制参考线（Draw guides）***：如果控制器是形状图层，勾选此项可显示一些设置 IK 用的实用参考线。  
        会显示限制值，方便你调整。

![](/docs-img/duik/constraints/1l-ik-guides_00000.png)  
*带参考线的 IK 控制器，显示限制值，以及用红色标出的*完整旋转限制*。*

### 两层链

<Video src="https://rxlaboratory.org/wp-content/uploads/rx-videos/Duik17_E04_Arm__EN_720.mp4" caption="本视频是 Duik Ángela 官方完整视频课程的一部分" />

用两个图层时，两层的旋转都会被自动化，在两个关节和控制器之间形成一个三角形；这对手臂和腿来说非常自然。

![](/docs-img/duik/constraints/2l-ik_00000.png)

动画化控制器的位置、或第一层（或其任一父级）的位置时，肢体会自动旋转和弯曲。通过这个 IK 设置，Duik 还控制肢体的位置，让它们能够拉伸（或收缩），从而实现透视缩短效果。  
如果绑定图层时存在末端图层（例如手、脚……），它可以通过控制器的旋转属性来旋转。

Duik 还内置了不错的自动化来辅助用 FK 做动画，让它更简单快捷——虽然它本来就已经比 IK 动画简单得多。

所有这些都可以在控制器的效果中配置和动画化。

![](/docs-img/duik/constraints/2l-ik-effect.png)

- ***IK / FK***：如果你需要用 FK 做动画，可以禁用 IK；它可以被做成动画。
- ***权重（Weight）***：它混合 IK 和 FK 动画，让两者之间平滑过渡。  
    设为 `0 %` 实际上就是停用 IK。
- ***侧别（Side）***：关节（例如肘或膝）偏向哪一侧，可以用这个值控制。  
    `100 %` 在一侧，`-100 %` 在另一侧。中间的值允许平滑过渡，用来动画化肢体的透视缩短或伪 3D 旋转。
- ***自动摆动（Auto swing）***根据特定角度自动切换侧别。  
    为帮你精确设定这个界限，你可以用参考线把它可视化。
- ***FK***：要用 FK 做动画，需要先禁用 IK（或把权重设为 `0 %`）。  
    然后你就可以动画化这些旋转值，用 FK 来动画化肢体。
    - ***父级旋转（Parent rotation）***：勾选后，肢体会随其父级旋转。  
        取消勾选则确保无论祖先如何旋转，肢体始终保持自己的朝向。
    - ***上部（Upper）***是第一层（根部，例如大腿）的旋转。
    - ***下部（Lower）***是第二层（例如小腿）的旋转。
    - ***末端（End）***是末端图层（例如脚）的旋转，如果存在的话。  
        这个图层其实并不属于 IK/FK 设置的一部分，但能直接在这个效果里动画化它很方便。
- ***FK 重叠（FK Overlap）***：  
    与其手动动画化两三个 FK 旋转值，这种带自动重叠动画[*](../../misc/glossary)的 FK 可以帮你用单个值动画化整条肢体。
    - ***重叠（Overlap）***：勾选此项以启用自动重叠动画。
    - ***动画（Animation）***是你可以动画化、从而自动动画化整条肢体的属性。  
        例如走路循环里摆动手臂时，效果尤其好。
    - ***灵活度（Flexibility）***调整重叠动画的量。它是一个任意值。
    - ***阻力（Resistance）***调整肢体各部分旋转之间的延迟。它是一个任意值。
- ***拉伸（Stretch）***：
    - ***自动拉伸（Auto-Stretch）***在肢体短到够不到控制器位置时拉伸[*](../../misc/glossary)它。
    - ***拉伸（Stretch）***同时拉伸肢体的第一层和第二层，保持它们的相对长度。
    - ***上部拉伸（Upper stretch）***拉伸第一层（例如大腿）。
    - ***下部拉伸（Lower stretch）***拉伸第二层（例如小腿）。
- ***数据（Data）***区段包含 Duik 计算动力学所需的一些数据。
- ***显示（Display）***：  
    - ***绘制参考线（Draw guides）***：如果控制器是形状图层，勾选此项可显示一些设置 IK 用的实用参考线。  
        会显示自动摆动界限，方便你调整其值。

<Callout type="success">
    效果的数据区段会暴露一些有用的值，方便你编写自己的表达式，或与连接器配合使用，做出更高级、更自定义的绑定。
</Callout>

<Callout type="success">
    你可以用[动画面板](../animation)中的 [IK/FK 切换](../animation/tools/ik-fk-switch)&nbsp;[^4]工具，在 IK 和 FK 动画之间轻松切换。
</Callout>

![](/docs-img/duik/constraints/2l-ik-guides_00000.png)  
*带参考线的 IK 控制器，显示自动摆动界限。*

### 三层链

给三个关节（及更多）的肢体做绑定，比看起来要复杂。在二维、只有两个关节时，定义各部分旋转的方程只有两个解（中间关节，即肘或膝，只能位于穿过第一关节和控制器连线的两侧之一）。但有三个关节时，解有无穷多个。

除了这个困难，如果我们不给更多细节就对三个关节使用标准 IK，就意味着动画师在需要时无法手动调整每个关节。绑定应该让动画师的生活更轻松，而绝不是束缚他们的工作。

正因如此，Duik 不包含真正的三层 IK，而是用更好的控制和精度来绑定三层链——它把标准的单层和两层 IK 组合起来。

有两种方案：用单层 IK 绑定第一层、再用标准两层 IK 绑定后两层；或者反过来，前两层先用两层 IK。两种方式下，Duik 都为这两个 IK 控制创建同一个控制器，只需控制器的位置就能非常简单地完成动画，所有细节控制都汇集在控制器的效果里。  
你可以在 *![](/docs-img/duik/icons/ik.svg) IK* 按钮的附加面板里在两者之间选择。

![](/docs-img/duik/constraints/3l-ik-options.png)

- ***2+1 层 IK***在第一层创建单层 IK，在第二、三层创建两层 IK。  
    ![](/docs-img/duik/constraints/2+1l-ik_00000.png)  
    例如螃蟹腿就最适合这种模式——最后一层的旋转必须被精确控制。  
    动画化控制器的位置来动画化整条肢体，动画化它的旋转来控制最后一层（蓝色）的朝向。
- ***1+2 层 IK***在第一、二层创建两层 IK，在第三层创建单层 IK。  
    ![](/docs-img/duik/constraints/1+2l-ik_00000.png)  
    例如带肩部的手臂最适合这种模式——第一层的旋转需要与其他层分开控制，但可以用单层 IK 的权重来自动化。  
    动画化控制器的位置来动画化整条肢体，用单层 IK 权重来调整第一层（蓝色）的自动旋转，或动画化它的 FK 值来手动旋转。

![](/docs-img/illustration/Kinematics_of_Machinery_-_Figure_21.svg)

## Bézier IK

超过两、三节骨骼的骨骼链，通常用来绑定柔软的肢体，比如尾巴、脊柱、长脖子或发束。这种情况下，链不是用分散的关节来动画化，而是作为一条长曲线整体动画化。动画化它有两个选择：

- 使用 **FK**：如果肢体只是悬挂着（比如发束、布料、尾巴）、只在一侧附着，FK 最好。
- **Bézier IK**：这是一种特殊的 IK，你可以用多个控制器来定义肢体的曲线，就像用点和切线控制 Bézier 路径那样。  
    如果链在两侧都与别的东西相连（附着），比如脊柱、脖子，或是那只尾巴夹在门缝里的狗——哎哟——这种最好。

![](/docs-img/duik/constraints/bezier-ik_00000.png)  
*用 Bézier IK 控制的四个图层*

用 Bézier IK 动画化肢体有三个控制器：

- 一个*根部（Root）*位置控制器，可用来移动肢体根部。  
    它通常父子化到身体其余部分（尾巴连到髋部，头发连到头，等等）。
- 中间一个*曲线（Curve）*控制器，用它的位置值帮你动画化肢体的弯曲。
- 末端是真正的 IK 控制器，用来移动肢体末端。

有两个效果用来调整细节：

- 在肢体末端的控制器上（主控制器）：  
    ![](/docs-img/duik/constraints/bezier-ik-effect.png)
    - 默认情况下，各图层对齐在虚拟曲线上（与曲线相切）。你可以取消勾选 ***自动定向（Auto orient）***选项，手动动画化它们的旋转。
    - 用 ***偏移（Offset）***让图层沿虚拟曲线移动。注意这个选项也**可以在每个图层上单独设置**。
- 在*曲线*控制器上：  
    ![](/docs-img/duik/constraints/bezier-ik-curveeffect.png)
    - 取消勾选 ***绘制参考线（Draw guides）***选项，可隐藏代表 IK 的虚线。
    - 你可以勾选 ***显示手柄（Show handles）***选项，显示次级控制，更精确地调整虚拟曲线。

![](/docs-img/duik/constraints/bezier-ik-curve_00000.png)  
*显示曲线手柄时，你可以非常精确地调整虚拟 Bézier 曲线。  
双击手柄即可四处移动它。*

可选的 Bézier 手柄实际上是*曲线*控制器形状图层内容里的组；要动画化它们，就动画化这些组的位置。

## 带重叠动画的 FK

FK 绑定是一种非常简单的控制器，用来控制一长串（或短串）骨骼链的所有旋转，可以单独控制，也可以整体控制。它专门为轻松动画化尾巴、布料、发束、围巾等而做。

当你用单个值整体动画化整条肢体时，Duik 可以自动替你处理细致的动画——用一种完全可自定义的自动重叠动画。

![](/docs-img/examples/carpes-structures.gif)  
*Claude Autret "Jissse"  
保留所有权利*  
*鱼尾用 FK 控制和自动重叠动画绑定。*

![](/docs-img/duik/constraints/fk_00000.png)  
*用 FK 控制同时控制的四个图层。*

要动画化肢体，你只需**动画化控制器的旋转**。

<Callout type="success">
    调整动画的**起始姿势**、在控制器的旋转上**打第一个关键帧**时，你还需要调整链中**第二个图层的 *角度（Angle）*值**（在控制器效果里），来固定这个姿势。这是因为自动重叠动画无法控制第一个姿势——它需要动画数据来处理角度，而第一个关键帧之前没有动画。出于性能原因，Duik 还会忽略所有隐藏在合成开始之前的关键帧。
</Callout>

要调整自动重叠动画的设置，控制器上提供了一个 *FK 重叠（FK Overlap）*效果。

![](/docs-img/duik/constraints/fk-overlap-effect.png)

- ***灵活度（Flexibility）***调整链中每个图层运动的幅度。
- ***阻力（Resistance）***调整重叠的时间。例如在水里，这个值会比在空气里更高。
- 你可以用 ***拉伸（Stretch）***调整肢体长度。如果图层链接到了木偶图钉上（用[骨骼](../bones)和/或 Duik [图钉](pins)），这就很好用。
- 用 ***曲线（Curve）***值调整肢体的整体弯曲。这个值不应被做成动画（动画请用控制器的旋转）。
- 如果勾选了 ***父级旋转（Parent rotation）***，肢体会随其父级旋转。例如尾巴就用这个。  
    取消勾选则确保无论祖先如何旋转，肢体始终保持自己的朝向。例如围巾或发束就可以用这个，让它无论头怎么转都保持竖直。
- 你可以设置 ***限制（limits）***来约束每个单独部分的旋转。这对于灵活度或阻力很大的肢体很有用。

最后，被控制链的每个图层都会添加一个角度控制，让你像所有标准 FK 绑定那样，单独调整和动画化每个部分。

## Bézier FK

Bézier FK 是一种特殊设置，以标准 Bézier IK 为基础，加上一些简单表达式和父子关系，从而能够同时用*伪* FK 和 Bézier IK 来动画化。它非常适合动画化脊柱或脖子，或是任何自身还带子级的链（比如脖子之于头），以及你可能大部分动画用 FK、但特定情况下需要 IK 的情形。

![](/docs-img/duik/constraints/bezier-fk_00000.png)  
*用 Bézier FK 控制的四个图层*

用这个 Bézier FK，你拥有**和 Bézier IK 完全一样的控制**（动画化控制器的位置，用链中央的控制器控制弯曲），但**你还可以动画化控制器的旋转**，就像用标准 FK 那样。  
这种情况下，Duik 会自动移动*曲线*控制器，你可以用肢体末端控制器上的 ***自动曲线（Auto-Curve）***效果来调整这个自动化。

[^1]: 由于手或脚的运动实际上是肘和肩、或膝和髋旋转的结果，它们自然地沿平滑曲线运动。而在 After Effects 里动画化位置时，默认轨迹是直线，并非如此。用 IK 做动画时，如果你不分离维度、不手动处理每个轴各自的插值，就得用钢笔工具调整位置关键帧的空间 Bézier 插值。

[^2]: *参见*[*骨骼与自动绑定*](../bones)。

[^3]: *参见*[*控制器*](../controllers)。

[^4]: *参见*[*动画 / 工具 / IK/FK 切换*](../animation/tools/ik-fk-switch)。
