# <img src="/docs-img/duik/icons/list.svg" style={{width: '1em'}}/> 列表

*列表（List）* 是一个简单的工具，可以把不同的动画和表达式叠加到同一个属性上。

要创建列表，**选中该属性**，然后点击 **<img src="/docs-img/duik/icons/list.svg" style={{width: '1em'}}/> *列表*** 按钮。

如果该属性原本已经被赋予了表达式，表达式和现有的关键帧会自动被复制到列表的第一个槽位中。

列表会以效果的形式添加到图层上。你最多可以叠加五个动画和表达式；如果还需要更多槽位，可以再复制这个列表效果。

![](/docs-img/duik/constraints/list.png)

<Callout type="info">
    混合结果按以下方式计算（颜色除外；颜色的计算函数取决于混合模式）：
</Callout>

```
value1 * weight1 + value2 * weight2 + value3 * weight3 + value4 * weight4 + value5 * weight5
```

列表可以用于**任何数值型属性[*](../../misc/glossary)，包括颜色**。

<Callout type="success">
    如果要把它用在 Bézier 路径属性上，可以先添加 [Duik 图钉](../pins)&nbsp;[^1] 来控制路径，然后再对图钉的位置（和旋转）属性使用列表。
</Callout>

用在颜色上时，该效果会略有不同：

![](/docs-img/duik/constraints/list-color.png)

列表中的每一个值，都会按照不透明度和混合模式，混合到上一个槽位中。

<Callout type="success">
    借助可设置关键帧的权重[*](../../misc/glossary)，你可以用列表来开启或停止任意表达式；也可以用它来组合不同的表达式，比如把一个正弦函数和多个抖动（wiggle）函数叠加在一起。此外，它还可以通过 *[连接器](../connector)*&nbsp;[^2]，把从属属性同时连接到多个主属性上。
</Callout>

[^1]: 参见 *[约束 / 连接器](../connector)*。

[^2]: 参见 *[约束 / 图钉](../pins)*。
