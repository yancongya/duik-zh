# <img src="/docs-img/duik/icons/zero.svg" style={{width: '1em'}}/> 归零

在 After Effects 中（和所有使用对象父子关系的动画软件一样），图层的坐标总是相对于其父级给出的；这就导致改变父子链接时数值会发生变化。

**选中一个图层**，然后点击 ***<img src="/docs-img/duik/icons/zero.svg" style={{width: '1em'}}/> 添加归零（Add Zero）*** 按钮，即可把它所有的变换属性清零。  
`[Alt] + [点击]`：把所选图层的变换属性重置为 `0`，  
`[Ctrl] + [Alt] + [点击]`：同时把不透明度也重置为 `100 %`。

*归零（Zero）* 正是利用了这一特性，让图层变换之间、甚至跨合成的表达式链接变得更容易。

一个 Zero 就是一个标准的空对象，它的变换数值与所作用的图层完全相同，被插入到层级中——位于该图层与其原父级之间。

这样一来，该图层的所有变换数值现在都相对于它的 *归零层*（位于同一位置）给出，并被初始化为：位置 `[0 px, 0 px]`、旋转 `0°`、缩放 `[100 %, 100 %]`。

对多个图层使用归零后，即使它们不在同一位置、甚至位于不同合成中，也能非常轻松地用表达式把它们的位置链接起来。

另一个好处是：使用归零后，图层的原始位置很容易找回——只需把它的所有坐标设为 `0` 即可。给角色绑定时给所有控制器都加上归零层，以便随时恢复休息姿势，是一个非常常见的技巧。

<Callout type="warning">
    归零层添加之后，如果你想改变所作用图层的父级，注意要改的是归零层的父级，而不是图层本身的父级，这样才能让归零层留在层级中。
</Callout>
