# <img src="/docs-img/duik/icons/lock.svg" style={{width: '1em'}}/> 锁定属性

要防止某个属性被编辑或被设置动画，可以把它锁定。  
选中该属性，然后点击 ***<img src="/docs-img/duik/icons/lock.svg" style={{width: '1em'}}/> 锁定属性*** 按钮。

要解锁该属性，只需删除它的表达式即可。

<Callout type="info">
    被创建的表达式只包含该属性的当前数值，从而把它牢牢锁定在这个值上。
</Callout>
