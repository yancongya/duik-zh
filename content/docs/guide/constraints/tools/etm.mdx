# <img src="/docs-img/duik/icons/expose_transform.svg" style={{width: '1em'}}/> 暴露变换

*暴露变换（Expose Transform）* 是一个对象（一个控制器），用来测量并**暴露两个图层之间的角度、方向、坐标和距离**；这些数值可以作为主属性，配合 [*连接器*](../connector)&nbsp;[^1] 使用，也可以写进你自己的表达式。

![](/docs-img/duik/constraints/etm.png)

和任何 [*控制器*](../../controllers)&nbsp;[^2] 一样，只需点击 <img src="/docs-img/duik/icons/expose_transform.svg" style={{width: '1em'}}/> *暴露变换* 按钮即可创建它。如果创建前选中了某个图层，暴露变换对象会创建在该图层的同一位置，并以该图层命名。

默认情况下，它会测量所选图层的变换；所有相对坐标都相对于该图层的父级图层测量。

所有数值和测量结果都会暴露在控制器图层所带的效果中。

![](/docs-img/duik/constraints/etmEffect.png)

你可以通过效果最前面的几个参数来更换被测量的图层。

- *目标图层（Target Layer）*：其变换被暴露的图层。
- 取消勾选 *使用父级（Use Parent）*，即可让相对变换不再相对于父级图层测量，而相对于另一个图层测量。
- *参考图层（Reference Layer）*：所有相对变换测量所依据的参考图层。

该效果暴露的所有数值，都可以用在表达式中，或配合 [*连接器*](../connector)&nbsp;[^1] 使用。
