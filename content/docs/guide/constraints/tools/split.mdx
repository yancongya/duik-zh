# <img src="/docs-img/duik/icons/separate_dimensions.svg" style={{width: '1em'}}/> 拆分数值

使用本工具可以拆分所选属性的各个维度。关键帧会被复制到拆分后的各个维度上。

Duik 会创建一个包含拆分后维度的效果。

![](/docs-img/duik/constraints/split.png)

这对颜色同样有效！你可以拆成 RGB 通道或 HSL，并对每个通道单独做动画。

![](/docs-img/duik/constraints/split-colors.png)
