# <img src="/docs-img/duik/icons/unlink.svg" style={{width: '1em'}}/> 编辑模式

有时你需要调整某个图层的位置，但又不想连带移动它的所有子级图层。这时，选中该图层（或多个图层），用 Duik 切换 *编辑模式*。

Duik 会自动、临时地解除所有子级图层的父子关系，让你可以轻松重新摆放该图层，然后再退出编辑模式。

开启编辑模式后，图层会变成红色来提醒你（通过 *着色（Tint）* 效果实现），并且会被添加一个图层标记，直到你关闭编辑模式。
