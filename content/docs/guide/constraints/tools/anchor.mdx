# <img src="/docs-img/duik/icons/move_anchor_point.svg" style={{width: '1em'}}/> 移动锚点

在 After Effects 中移动（并精确对齐）锚点往往非常麻烦，尤其是当锚点已经做了动画，或者要同时移动多个锚点时。

使用本工具，可以轻松地重新定位锚点——即使锚点带有动画，或者要同时处理多个图层。

点击 ***<img src="/docs-img/duik/icons/move_anchor_point.svg" style={{width: '1em'}}/> 移动锚点*** 按钮，打开该工具。

![](/docs-img/duik/constraints/mmove_ap.png)

1. **选中**若干图层
2. **点击**面板中的九个按钮之一。

如果移动锚点时把蒙版也纳入计算，锚点将不再对齐图层的边界，而是对齐蒙版 Bézier 路径的边界。

可以设置边距（margin），让锚点相对精确边界产生偏移。
