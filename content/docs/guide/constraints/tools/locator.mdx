# <img src="/docs-img/duik/icons/locator.svg" style={{width: '1em'}}/> 定位器

*定位器（Locator）* 是 <img src="/docs-img/duik/icons/parent_across_comp.svg" style={{width: '1em'}}/> [*跨合成父子*](../parent)&nbsp;[^1] 工具所使用的对象，在某些场合非常有用。它们是空对象图层，会无条件跟随另一个图层，并获取（同时暴露）该图层的所有绝对变换数值。

你可以随时在合成中添加一个定位器；而 **<img src="/docs-img/duik/icons/extract_locator.svg" style={{width: '1em'}}/> *提取定位器*** 工具，可以从选中的预合成图层中提取出所有定位器，让它们直接在主（容器）合成中可用。这正是 <img src="/docs-img/duik/icons/parent_across_comp.svg" style={{width: '1em'}}/> [*跨合成父子*](../parent)&nbsp;[^1] 工具背后的原理。

提取定位器时，你可以选择使用表达式或基本属性。在 <img src="/docs-img/duik/icons/extract_locator.svg" style={{width: '1em'}}/> *提取定位器* 按钮上 `[Shift] + [点击]` 即可打开这个选项。当把子图层跨合成父子绑定到父级时，如果子图层位于预合成中（而不是"父级"合成中），也会沿用这个选项。

<Callout type="warning">
    请勿修改定位器变换属性上的表达式，也不要在其上添加关键帧，否则可能破坏 Duik 的其他一些工具。如果你需要对定位器做绑定，只需在层级中再插入一个空对象图层：让它作为定位器的子级，再把原来定位器的子级图层父子到它上面即可。
</Callout>

[^1]: 参见 [*约束*](..) / [*父子约束*](../parent)。
