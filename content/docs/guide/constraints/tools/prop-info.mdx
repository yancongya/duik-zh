# <img src="/docs-img/duik/icons/help.svg" style={{width: '1em'}}/> 属性信息

选中一个属性，然后点击 <img src="/docs-img/duik/icons/help.svg" style={{width: '1em'}}/> ***属性信息*** 按钮，就能获得该属性的一些有用信息，比如它的索引、匹配名称、在表达式中的路径……

![](/docs-img/duik/constraints/propinfo.png)

勾选 **高精度（Hi-precision）** 复选框，可以更精确地对数值和速度进行采样；但要注意，在非常长的合成中这可能会相当耗时。
