# ![](/docs-img/duik/icons/help.svg) Property Info

Select one property and click on the ![](/docs-img/duik/icons/help.svg) ***Property Info*** button to get some useful information about the property, like its index, its match name, its path in expressions…

![](/docs-img/duik/constraints/propinfo.png)

Check the **Hi-precision** checkbox to sample the values and velocities more precisely, but be careful as this can be quite long in very long compositions.
