# <img src="/docs-img/duik/icons/shape_key.svg" style={{width: '1em'}}/> 形态关键帧

<Video src="https://rxlaboratory.org/wp-content/uploads/rx-videos/Duik17_H01_KeyMorph01__EN_720.mp4" caption="本视频是 Duik Ángela 官方完整视频课程的一部分" />

形态关键帧是一种简单却非常强大、灵活的插值[*](../../misc/glossary)工具。它能够在关键姿势之间变形，或把它们混合在一起[^3d]，而且可以使用 After Effects 中的任意属性（只要该属性能被表达式控制）。这对于控制面部表情（情绪与表情、转头、唇形同步……）特别有用，也适用于任何基于特定姿势的动画（例如复杂的手部形状）。

[^3d]: 这在 3D 软件里是一种非常常见的技术。在 *Blender* 中叫做 *Shape Keys*，在 *Cinema 4D* 中叫 *Pose Morph*，在 *Maya* 中叫 *Blend Shapes*，在 *3DS Max* 中叫 *Morpher*……

![](/docs-img/illustration/keymorph.gif)

要设置形态关键帧，第一步是**创建真正的关键姿势**，方法就是在构成姿势的属性上**添加所需的关键帧**。

第一个关键帧必须是*中立*姿势，其他姿势都将从它插值而来（转头时正面朝前；准备面部表情时为中性情绪；等等）。

![](/docs-img/duik/constraints/keymorph-keys.png)  
*准备好被*形态关键帧*控制的关键帧。  
注意，这些关键帧也可以分散在多个图层上。*

所有要控制的属性都必须有相同数量的关键帧；必要时你可以复制粘贴第一个关键帧来补全关键帧集合。

基于这样一组关键帧，形态关键帧会添加简单的控制器，既可以在任意关键姿势之间插值（它能从第一个姿势直接插值到第四个，而不必经过第二、第三个），也可以按照你能做成动画的任意比例，把这些关键姿势混合在一起。  
只需**选中所有关键帧**，然后**点击 ![](/docs-img/duik/icons/shape_key.svg) *形态关键帧* 按钮**。

Duik 会在图层上添加一堆效果。

![](/docs-img/duik/constraints/keymorph-effects.png)  
***形态关键帧*效果。**

形态关键帧有两种使用方式：

- 在关键姿势之间**插值**。  
    例如在对话过程中给嘴部做动画（这叫做唇形同步）。这种情况下，你只想在正确的时机**一个接一个**地选发音素，并在它们之间插值，而不需要把它们混合在一起。
- **混合**不同的姿势。  
    例如做面部表情时，你可能需要同时转头、张开嘴、露出微笑、扬起眉毛，所有这些**同时进行**。

## 在关键姿势之间插值

用默认设置，你可以很容易地在关键姿势之间插值，使用第一个*形态关键帧*效果：

1. 保持 ***权重（Weights）归一化***。  
    这能确保没有外推，各姿势之间平滑插值。
2. **动画化 *关键选择（Key Selection）***属性。  
    每个姿势从 `1` 开始编号，一直到姿势的数量。不要用 `0`；第一个、也就是中立姿势的编号是 `1`。

关键姿势很多时，可能很难记住每个姿势对应的数字（即*索引*）；这时你可以稍微改进一下默认的形态关键帧设置。

### 使用标记

你可以为每个姿势添加一个标记，记录它们是什么、包括各自的索引。  
![](/docs-img/duik/constraints/keymorph-markers.png)

要添加标记，选中图层并按 `[*]` 键。然后你可以双击新标记来添加注释。

### 用连接器搭配更好的控制器来控制形态关键帧

#### 用菜单

在大多数情况下，使用下拉菜单非常方便。

1. 创建一个下拉菜单控件。  
    编辑它，列出各个姿势。  
    ![](/docs-img/duik/constraints/keymorph-create-dropdown.png)
2. 用 *![](/docs-img/duik/icons/connector.svg) [连接器](connector)*&nbsp;[^cnctr] 把它链接到关键姿势。  
    1. 选中新建的下拉效果（时间线里的属性，而不是效果本身）。
    2. 在连接器附加面板中，点击 *![](/docs-img/duik/icons/pick_prop.svg) **拾取属性（Pick Property）*** 按钮。
    3. 在带形态关键帧设置的图层上，选中要连接的 *Key* 效果。
    4. 在连接器附加面板中，点击 *![](/docs-img/duik/icons/shape_key.svg) **形态关键帧（Key Morph）*** 按钮。

![](/docs-img/duik/constraints/keymorph-dropdown.png)

现在你只需动画化这个效果，就能在关键姿势之间插值了。

#### 用滑块

你也可以在视口里创建一个滑块，举例来说。

1. 用 *![](/docs-img/duik/icons/connector.svg) [连接器](connector)*&nbsp;[^cnctr] 或 *[控制器](../controllers)*[^ctrls] 面板创建一个滑块。
2. 在带形态关键帧设置的图层上，选中要连接的 *Key* 效果。
3. 在连接器面板中，点击 *![](/docs-img/duik/icons/shape_key.svg) **形态关键帧（Key Morph）*** 按钮。

[^cnctr]: *参见*[*链接与约束*](index) / [*连接器*](connector)。

[^ctrls]: *参见*[*控制器*](../controllers)。

## 混合多个关键姿势

要能够混合多个关键姿势，先在图层上第一个*形态关键帧*效果里调整这些设置：

- **把 *关键选择（Key Selection）*设为 `0`** 来禁用它。
- **取消勾选 *权重（Weights）*的 *归一化（Normalize）*复选框**，以便能够外推并把多个姿势混合在一起。

现在你只需动画化图层上每个 *Key* 效果的 *权重（Weight）*百分比值。Duik 会漂亮地把这些姿势混合在一起，你想混合多少个都行。

<Callout type="success">
    *权重*值不限制在 `0 %` 到 `100 %` 之间，方便你轻松地反转或外推每个姿势。
</Callout>

<Callout type="success">
    你可以用表达式，或把各 Key 的 *权重*属性链接到自定义控制器上，比如 Duik [滑块](../controllers)或表达式控制效果，从而在另一个合成和控制器图层上控制它们。
</Callout>

## 编辑关键姿势

形态关键帧创建之后，你仍然可以编辑、添加或删除关键姿势。

1. 停用你要编辑的属性中的表达式。
2. 编辑关键帧；你也可以添加或删除关键姿势。
3. 如果你删除了一些关键姿势，就删除一些 *Key* 效果，使数量与姿势一致。  
    如果你新建了关键姿势，就复制最后一个 *Key* 效果，使数量与姿势一致。
