# <img src="/docs-img/duik/icons/constraints.svg" style={{width: '1em'}}/> 链接与约束

绑定的核心，是骨骼、图层或属性之间的链接与约束。你可以把约束想象成驱动木偶的丝线与机关；[骨骼](../bones)[*](../../misc/glossary)是骨架，而那些把手就是动画用的[控制器](../controllers)。

![](/docs-img/illustration/duik15.png)

约束有很多种，但它们几乎都以同一种方式工作——一种因果、父子、主从关系。
