# <img src="/docs-img/duik/icons/constraints.svg" style={{width: '1em'}}/> 变换约束

变换约束可以约束（也就是链接）一个图层的位置与旋转，让它跟随其他图层和 Bézier 路径的位置与朝向。

在绑定各种机械、齿轮，或是布料时，它们非常好用——例如配合木偶图钉、Bézier 路径和 [Duik 图钉](pins)&nbsp;[^1]，把它们约束到肢体与关节的朝向或位置上。

![](/docs-img/illustration/Elementary_treatise_on_the_finishing_of_white,_dyed,_and_printed_cotton_goods_(1889)_(14597187638).png)  
*《白色、染色与印花棉布整理基础论》  
Joseph Depierre，1889  
公有领域。*

大多数时候，同样的效果也能用连接器实现，但连接器给出的是不受限的数值。而当存在多个主控图层时，使用约束也更方便。

选中要约束的图层，然后点击 **![](/docs-img/duik/icons/constraints.svg) 变换（Transform）…** 按钮，选择要应用到选区的约束。

![](/docs-img/duik/constraints/transform.png)

<Callout type="success">
    图层被约束后，它的旋转和位置并不会被锁定；你仍然可以手动编辑并制作动画，从而偏移约束值。
</Callout>

## <img src="/docs-img/duik/icons/move.svg" style={{width: '1em'}}/> 位置约束

你可以把一个图层的位置约束到其他图层的位置上；这意味着被约束图层会根据其他图层的绝对位置进行平移，并把所有父级的平移都考虑在内。权重[*](../../misc/glossary)作为约束的乘数，可以被做成动画。  
例如，如果一个图层以各 `50 %` 的权重被约束到另外两个图层上，它就会停在连接这两个图层线段的中点。三个图层、各 `33.3 %` 时也同样有效，可以把图层附着到这些图层的质心上。当然，你可以调整权重来改变主控图层的“质量”。

你可以用效果来调整并制作位置约束的动画。

![](/docs-img/duik/constraints/position-constraint-effect.png)

只需选择要约束到的图层，并设置或动画化它的权重即可。要约束到多个图层，可以复制这个效果。

<Callout type="info">
    由于这个约束依赖图层在合成开始时的具体位置，只有当主控图层上确实存在动画（关键帧或表达式）、并且在合成的第一帧时，你才会看到位置约束的效果。
</Callout>

## <img src="/docs-img/duik/icons/rotate.svg" style={{width: '1em'}}/> 方向约束

你可以把一个图层的旋转约束到其他图层的朝向上；这意味着被约束图层会根据其他图层的绝对朝向进行旋转，并把所有父级的旋转都考虑在内。权重[*](../../misc/glossary)作为约束的乘数，可以被做成动画。

![](/docs-img/examples/ferriswheel.gif)  
*Léa Saint-Raymond  
保留所有权利。*

当你需要一个图层始终与另一个图层保持对齐、但不随它平移时，这是个非常实用的工具。  
你也可以用这个约束，把某个控制器的朝向链接到绑定中任意图层的朝向上；这是一种在不使用父子关系的情况下控制绑定旋转的快捷方式。

你可以用效果来调整并制作方向约束的动画。

![](/docs-img/duik/constraints/orientation-constraint-effect.png)

只需选择要约束到的图层，并设置或动画化它的权重即可。要约束到多个图层，可以复制这个效果。

<Callout type="success">
    当所有方向约束都设为 `0 %` 时，无论如何被约束的图层都保持自己的朝向，即使它有父级也是如此。举例来说，这就能很方便地给摩天轮的座舱或自行车的脚踏做绑定。
</Callout>

## <img src="/docs-img/duik/icons/bezier.svg" style={{width: '1em'}}/> 路径约束

要让一个图层沿 Bézier 路径移动（并与路径保持对齐），可以使用路径约束。它同时约束图层的位置和旋转。

![](/docs-img/illustration/Elementary_treatise_on_the_finishing_of_white,_dyed,_and_printed_cotton_goods_(1889)_(14597187638)_2.png)  
*《白色、染色与印花棉布整理基础论》  
Joseph Depierre，1889  
公有领域。*

1. 点击 **![](/docs-img/duik/icons/bezier.svg) 路径约束** 按钮。  
    ![](/docs-img/duik/constraints/path.png)
2. **选择路径**属性（注意不要选包含路径的组，而要选实际的路径属性）。
3. **点击 ![](/docs-img/duik/icons/eye_dropper.svg) 吸管**按钮。  
    ![](/docs-img/duik/constraints/path-picked.png)
4. **选择要约束的图层**。
5. **点击 ![](/docs-img/duik/icons/check.svg) 路径约束**按钮。  
    你可以 `[Alt] + [Click]`，把被约束图层自动移动到路径的第一个点。

你可以用效果来调整并制作路径约束的动画。

![](/docs-img/duik/constraints/path-constraint-effect.png)

- 你可以用第一个百分比值**让图层沿路径移动**；由于这个值不限于 `0 - 100 %`，你可以轻松地让动画循环。
- 你可以用**路径偏移（Path Offset）**属性，沿路径上对应百分比处的法线方向，让图层偏离路径。
- 默认情况下，图层会旋转到与路径相切。取消勾选**朝向（Orientation）**选项即可关闭此行为。

<Callout type="success">
    如果路径本身被做成了动画，被约束图层会跟随路径的动画，即使“沿路径百分比”也在动画中也是如此。
</Callout>
