# <img src="/docs-img/duik/icons/effector.svg" style={{width: '1em'}}/> Effector

空间 Effector（效果器）是一种简便的方式，可以根据一个图层的位置——更准确地说，是根据由任意形状及其精确位置所定义的区域——来控制（大量）属性。

<Video src="https://rxlaboratory.org/wp-content/uploads/rx-videos/Duik17_G01B_Connector2__EN_720.mp4" caption="本视频是 Duik Ángela 官方完整视频课程的一部分" />

1. **制作从属属性动画**，让它们随 Effector 变化。
2. **选择要从属属性**，用空间 Effector 控制它们。
3. 点击 ![](/docs-img/duik/icons/effector.svg) ***Effector*** 按钮。

![](/docs-img/duik/automation/effector_00000.png)  
*一个控制图层颜色和旋转的 Effector。*

Effector 是 Duik 在合成中创建的一个简单形状图层；你可以移动它，或把它设为另一个图层的子级，Effector 图层（及其形状）的绝对位置控制着从属属性。

<Callout type="success">
    你可以平移 Effector，也可以旋转和缩放它。
</Callout>

你可以用图层上的效果来调整 Effector。

![](/docs-img/duik/automation/effector-effect.png)

从属属性的值会根据其图层的锚点相对于 Effector 形状的位置而变化，在限制之间过渡。

- ***内部限制***在 Effector 图层上以绿色显示。
- ***外部限制***以红色显示。
- ***模式***改变 Effector 的形状，可以是**圆形**、**无限直线**或**自定义形状**。
- 使用***插值***部分来改变数值在 Effector 限制之间过渡的方式。

使用*自定义形状*时，你可以通过修改形状图层内容中相应的 Bézier 路径来改变形状。

![](/docs-img/duik/automation/effector-content.png)  
*要编辑以调整 Effector 自定义形状的路径属性。*
