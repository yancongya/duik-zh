# <img src="/docs-img/duik/icons/random.svg" style={{width: '1em'}}/> 随机运动

<Video src="https://rxlaboratory.org/wp-content/uploads/rx-videos/Duik17_F08_Random__EN_720.mp4" caption="本视频是 Duik Ángela 官方完整视频课程的一部分" />

你可以用这个工具为某些属性生成一个**动画化的随机值**。

与[*Wiggle*](wiggle)相反，这种随机运动不经过插值：每个数值都是完全随机的，不会从前一个数值演变而来。这让数值在没有插值[*](../../misc/glossary)的情况下从一个值跳到另一个值；这对于伪造传统动画非常有用，例如让赛璐璐片稍微跳动，就像扫描时它们没有完美对齐一样，或用于生成非常急促的随机运动。

<Callout type="warning">
    不要把这个工具与[*Randomize*](tools/randomize)[^randomize]工具混淆：Randomize 生成的随机数值是不动画的，而且它可以用于各种属性，而不只是属性。
</Callout>

1. **选择**属性
2. 点击 ![](/docs-img/duik/icons/random.svg) ***随机运动***按钮

<Callout type="success">
    当你把随机运动应用在某些属性上，之后想在其他属性上使用同样的随机运动时，你只需在新的属性里复制并粘贴表达式即可。
</Callout>

## 效果

随机运动可以在第一个选中图层的效果中调整。

![](/docs-img/duik/automation/random-effect.png)

你可以勾选***链接尺寸***选项，在 X 和 Y 轴使用相同的数值；例如这对缩放属性很有用。

***细节***部分包含更多高级属性。

***自然（高斯分布）模式***感觉更真实、更自然；例如用在位置上时，图层会在一个圆形区域内围绕原始位置中心跳动。但这种模式下，数值可能会跳出精确幅度更远。  
***严格模式***感觉不那么自然，但数值严格限制在给定的幅度之内。

***随机种子***用于生成随机运动的伪随机性。默认情况下，它被设为图层的索引。

## 其他选项

在把随机运动添加到选中属性之前，你可以在 ![](/docs-img/duik/icons/options.svg) 附加面板中设置一些选项。

![](/docs-img/duik/automation/random-options.png)

- 尺寸  
    - ![](/docs-img/duik/icons/collapse_dimensions.svg) ***折叠尺寸***：为所有维度（或颜色的通道）使用单一的幅度和频率。
    - ![](/docs-img/duik/icons/separate_dimensions.svg) ***拆分数值***：为每个维度或颜色通道分离幅度和频率数值。
- 控制  
    - ![](/docs-img/duik/icons/unified_control.svg) ***统一控制***：为所有选中属性创建一个单一效果。
    - ![](/docs-img/duik/icons/individual_control.svg) ***独立控制***：为每个选中属性创建一个效果。

[^randomize]: 参见[*自动化*](index) / 工具 / [*Randomize*](tools/randomize)。
