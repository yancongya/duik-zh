# <img src="/docs-img/duik/icons/move_away.svg" style={{width: '1em'}}/> Move Away

<Video src="https://rxlaboratory.org/wp-content/uploads/rx-videos/Duik17_F07_MoveAwayMotionTrail__EN_720.mp4" caption="本视频是 Duik Ángela 官方完整视频课程的一部分" />

*Move Away* 工具会添加一个简单的滑块，用来控制图层与其父级之间的距离。

![](/docs-img/illustration/Fotothek_df_tg_0004802_Geometrie_Architektur_Festungsbau_Vermessung.jpg)  
*椭圆构造，匈牙利城市与奥芬要塞的景观，  
Anton Ernst Burkhard von Birckenstein，1698  
公有领域。*

1. **选择**图层。
2. 点击 ![](/docs-img/duik/icons/move_away.svg) ***Move Away*** 按钮

当你需要为两个不对齐、或者更糟、正在旋转的图层之间的距离制作动画时，这非常有用。当父图层旋转、子图层绕它旋转时，用起来尤其有趣，请看下面的练习。

## 练习！

这里有一个简单但有趣的练习，用来结合其他 Duik 自动化测试这个工具。

1. 在合成中央**创建一颗太阳**。它可以是任何图层，但最好不要是圆形，这样你之后才能看到它在旋转。
2. **创建一颗行星**、小行星、卫星或任何绕太阳公转的东西。
3. 把**行星图层设为太阳图层的子级**。
4. 选中行星图层，点击 ![](/docs-img/duik/icons/move_away.svg) ***Move Away*** 按钮。
5. **为太阳的旋转制作动画**。我们就在图层旋转上使用这个表达式：`time * 100;`。你可以把 `100` 改成任何数值来改变速度，或用指向滑块控制的链接替换。
6. 摆弄行星图层上的 *Move Away* 滑块，添加几个关键帧看看它会怎样。循环播放动画（用 Duik 或表达式）！
7. 选中行星图层，添加一个[***运动轨迹***](motion-trail)[^trail]，并调整设置。
8. 为了更有趣，移除 Move Away 滑块中的动画，添加一个[***Swink***](swink)[^swink]！
