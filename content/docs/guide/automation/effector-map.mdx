# ![](/docs-img/duik/icons/effector_map.svg) Effector Map

The effector map works similarly to the [spatial effector](effector.md)&nbsp;[^effctr] except it uses a texture layer instead of a shape.

<Video src="https://rxlaboratory.org/wp-content/uploads/rx-videos/Duik17_G01B_Connector2__EN_720.mp4" caption={"This video is part of [__the official comprehensive video course about Duik Ángela__](https://rxlaboratory.org/product/the-official-comprehensive-video-course-about-duik-angela/)"} />

1. **Animate the slave properties** as they should change with the effector.
2. **Select the texture layer**.
3. Click the ![](/docs-img/duik/icons/effector_map.svg) ***Effector Map*** button.  
    ![](/docs-img/duik/automation/effector-map.png)
4. **Select the slave properties** to be controlled with the effector map.
5. Click the ![](/docs-img/duik/icons/props.svg) ***Connect properties*** button.

You can tweak the effector with the effect on the texture layer.

![](/docs-img/duik/automation/effector-map-effect.png)

[^effctr]: *cf. [Automation](index.md) / [Effector](effector.md)*.
