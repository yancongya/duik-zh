# <img src="/docs-img/duik/icons/effector_map.svg" style={{width: '1em'}}/> Effector Map

Effector Map（Effector 贴图）的工作原理与[空间 Effector](effector)[^effctr]类似，只是它使用一个纹理图层而不是形状。

<Video src="https://rxlaboratory.org/wp-content/uploads/rx-videos/Duik17_G01B_Connector2__EN_720.mp4" caption="本视频是 Duik Ángela 官方完整视频课程的一部分" />

1. **制作从属属性动画**，让它们随 Effector 变化。
2. **选择纹理图层**。
3. 点击 ![](/docs-img/duik/icons/effector_map.svg) ***Effector Map*** 按钮。  
    ![](/docs-img/duik/automation/effector-map.png)
4. **选择要从属属性**，用 Effector Map 控制它们。
5. 点击 ![](/docs-img/duik/icons/props.svg) ***连接属性***按钮。

你可以用纹理图层上的效果来调整 Effector。

![](/docs-img/duik/automation/effector-map-effect.png)

[^effctr]: 参见[*自动化*](index) / [*Effector*](effector)。
