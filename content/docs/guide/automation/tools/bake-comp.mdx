# <img src="/docs-img/duik/icons/comp_baker.svg" style={{width: '1em'}}/> 烘焙合成

*烘焙合成*工具会尽可能简化整个合成，在不影响动画的前提下让它尽量轻，并让它更适合特定的导出，比如 HTML/JS/CSS 动画，例如 Lottie/Bodymovin。

- 它**移除图层上的所有父子关系**。  
    但会保留相同的动画，在图层上添加必要的关键帧，让它们保持完全相同的运动。
- 它**移除图层上的所有表达式**。  
    根据选项中设置的模式（*智能*或*精确*）。
- 它**移除所有不可渲染的图层**。  
    这些图层可以是：空对象图层、空的形状图层、没有效果且整个合成不透明度为 `0 %` 的调整图层，或参考图层（包括 Duik 控制器、骨骼和图钉）。

结果是一个没有任何多余图层、没有任何父子关系、没有任何表达式的合成。

*烘焙合成*工具与*烘焙表达式*工具拥有相同的选项。
