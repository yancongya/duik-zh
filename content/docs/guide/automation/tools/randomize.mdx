# <img src="/docs-img/duik/icons/randomize.svg" style={{width: '1em'}}/> Randomize

*Randomize* 工具能够随机化各种东西（属性值、关键帧时间、图层时间……）

首先，点击 ![](/docs-img/duik/icons/randomize.svg) *Randomize* 按钮打开 *Randomize* 面板。

![](/docs-img/illustration/Jean_Siméon_Chardin_-_A_Child_with_a_Teetotum_-_WGA04755.jpg)  
*L'enfant au toton（Portrait de Auguste Gabriel Godefroy），  
Jean-Baptiste-Siméon Chardin，1738  
公有领域。*

你可以选择随机化：

- **当前值**：随机化选中的属性，如果属性有动画，会在当前时间添加一个关键帧。
- **图层**：随机化图层的时间，或图层在堆叠中的位置。
- **关键帧**：随机化选中关键帧的数值或时间。

对于所有模式，你都可以选择模式：

- ***自然（高斯分布）模式***感觉更真实、更自然；例如用在图层位置上时，图层会在一个圆形区域内围绕原始位置中心分布。但这种模式下，数值可能会跳出精确幅度更远。  
- ***严格模式***感觉不那么自然，但数值严格限制在给定的幅度之内。

你还可以选择数值是添加到当前状态（***偏移***），还是完全替换现有数值（***绝对***）。

## 当前值

![](/docs-img/duik/automation/randomize-currentvalues.png)

如果你**拆分**多维数值，会显示三个轴；如果你随机化的是一个 2D 数值，可以忽略第三个轴。对于颜色，三个轴代表红、绿、蓝通道，范围从 `0.0` 到 `1.0`（在每通道 32 位项目的情况下可能更多）。

## 图层

![](/docs-img/duik/automation/randomize-layer.png)

- ***索引***在堆叠中上下移动图层。
- ***时间***在时间轴中移动图层。
- ***入点***和***出点***在指定时间剪切图层，而不移动它们。

## 关键帧

![](/docs-img/duik/automation/radomize-keyframes.png)

对于关键帧，你可以随机化它们的**时间**（并在时间轴中移动它们）或它们的**数值**。

如果你**拆分**多维数值，会显示三个轴；如果你随机化的是一个 2D 数值，可以忽略第三个轴。对于颜色，三个轴代表红、绿、蓝通道，范围从 `0.0` 到 `1.0`（在每通道 32 位项目的情况下可能更多）。
