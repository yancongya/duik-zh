# <img src="/docs-img/duik/icons/time-remap.svg" style={{width: '1em'}}/> 时间重映射

*时间重映射*是一种在选中图层上激活时间重映射并自动添加循环工具的快捷方式。

它会自动调整时间重映射属性中的关键帧，让它与循环更好地配合。最后一个关键帧是图层的字面最后一帧，而不是像 After Effects 通常那样是它之后的那一帧。

然后它会给时间重映射属性添加一个[*Looper*](../looper)[^loop]。

[^loop]: 参见[*自动化*](../index) / [*Looper*](../looper)。
