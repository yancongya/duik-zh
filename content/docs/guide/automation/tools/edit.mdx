# <img src="/docs-img/duik/icons/expression_file.svg" style={{width: '1em'}}/> 编辑表达式

这是一种在外部编辑器中打开任何表达式的快捷方式，比 After Effects 自带的表达式编辑器更容易编辑复杂表达式。

1. **选择**带表达式的属性。
2. 点击 ![](/docs-img/duik/icons/expression_file.svg) ***编辑表达式***按钮。
3. 完成后，在外部编辑器中**保存文件**。
4. `[Ctrl] + [Click]` 点击 ![](/docs-img/duik/icons/expression_file.svg) ***编辑表达式***按钮，在 After Effects 中更新它。

当表达式在外部编辑器中打开时，你可以根据需要不断编辑和保存表达式文件，并随时在 After Effects 中重新加载。

默认情况下，Duik 会使用与 `.js` 文件关联的默认应用程序打开表达式，但你可以设置要使用的编辑器：`[Shift] + [Click]` 点击***编辑表达式***按钮打开设置。

![](/docs-img/duik/automation/edit-options.png)

<Callout type="success">
    我们推荐使用 Microsoft Visual Studio Code 来编辑表达式。  
    它在 Windows 上的默认安装路径是  
    `C:\Users\YourName\AppData\Local\Programs\Microsoft VS Code\Code.exe`
</Callout>
