# ![](/docs-img/duik/icons/copy_expression.svg) Copy and ![](/docs-img/duik/icons/paste_expression.svg) Paste Expressions

Select a propoerty and click the ![](/docs-img/duik/icons/copy_expression.svg) ***Copy Expression*** button to **copy its expression**.

Click the ![](/docs-img/duik/icons/paste_expression.svg) ***Paste Expression*** button to **paste the copied expression in all selected properties**.

<Callout type="info">
    If you `[Right Click]` a property in After Effects, you already have the option to copy only the expression... But you can't paste it in multiple properties!
</Callout>
