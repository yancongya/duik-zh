# <img src="/docs-img/duik/icons/copy_expression.svg" style={{width: '1em'}}/> 复制和<img src="/docs-img/duik/icons/paste_expression.svg" style={{width: '1em'}}/> 粘贴表达式

选择一个属性，点击 ![](/docs-img/duik/icons/copy_expression.svg) ***复制表达式***按钮，**复制它的表达式**。

点击 ![](/docs-img/duik/icons/paste_expression.svg) ***粘贴表达式***按钮，**把复制的表达式粘贴到所有选中属性中**。

<Callout type="info">
    如果你在 After Effects 中`[右键单击]`一个属性，你已经有只复制表达式的选项……但你无法把它粘贴到多个属性中！
</Callout>
