# <img src="/docs-img/duik/icons/disable_expression.svg" style={{width: '1em'}}/> 切换表达式

选择一些带表达式的属性，点击 ![](/docs-img/duik/icons/disable_expression.svg) ***切换表达式***按钮，即可快速停用或重新启用这些表达式。

按住 `[Ctrl]` 可以移除表达式而不是停用它们。与 After Effects 不同，当你用 Duik 移除表达式时，属性的当前值会被保留（属性不会回到它们最初的、加表达式之前的值），除非你同时按住 `[Alt]` 键。
