# <img src="/docs-img/duik/icons/automation.svg" style={{width: '1em'}}/> 自动化与表达式

自动化、自动动画、动力学、物理、程序化动画……

角色一绑定好，你就可以在大量自动化的帮助下开始动画制作了。**自动化（Automations）**是一种程序化动画与动力学，可以快速搭建最常见的动画，然后把精力集中在角色的个性化上。你可以自动化抖动、弹簧、轮子等效果，并带有可自定义的高级控制，例如让效果循环，轻松快速地访问每一个细节。
