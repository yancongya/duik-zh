# <img src="/docs-img/duik/icons/walk_cycle.svg" style={{width: '1em'}}/> 行走/奔跑循环

*行走 / 奔跑循环*是一个综合性的程序化动画。

这是一种非常快速、简单的方式，可以开始制作行走和奔跑动画。一个漂亮的行走或奔跑循环只需一键即可获得，但你也可以深入细节，调整角色身高和体重，以及每个独立肢体的参数，精确设置它如何行走和奔跑……

![](/docs-img/illustration/Female_nude_motion_study_by_Eadweard_Muybridge_(2).jpg)  
*走下楼梯的女人，  
Eadweard Muybridge，1887  
公有领域。*

要使用行走 / 奔跑循环，你必须有一个已绑定的角色。不过它适用于任何已绑定的角色，即使不是用 Duik 而是用其他工具绑定的也可以。

![](/docs-img/examples/zombiedancerig.gif)

<Callout type="success">
    这个行走 / 奔跑循环是为两足动物制作的，但你可以用两个行走循环来实现四足行走循环：一个用于前腿、肩部、脖子和头，另一个用于后腿和臀部。你只需自己制作尾巴的动画并调整一些设置。
</Callout>

## 设置

在创建行走 / 奔跑循环之前，确保角色直立，双臂沿身体自然下垂。在行走 / 奔跑循环创建之后，你仍然可以移动控制器来调整姿势和行走的外观，甚至可以在自动动画之上为它们制作动画来进行调整。行走 / 奔跑循环的目的不是创造完美而有特色的动画。它是一个有用的工具，可以快速开始制作行走或奔跑动画，这些动画需要一些调整才能有个性，或用于快速为次要的、不太重要的角色制作动画。

如果角色是用预定义的肢体骨骼和 Duik 的自动绑定绑定的，使用行走循环就非常简单：

1. **选择**角色的所有控制器
2. 点击 ![](/docs-img/duik/icons/walk_cycle.svg) ***行走 / 奔跑循环***按钮

如果角色是用 Duik 的自定义骨骼绑定的，或用任何其他工具（*Rubberhose*、*BAO Bones*、*Limber*……）甚至自定义表达式绑定的，你也可以使用行走 / 奔跑循环，但你必须手动做一些简单的连接：

1. **选择**角色的所有控制器（用于制作动画的图层，或包含制作动画所需效果的图层）
2. 打开行走 / 奔跑循环的 ![](/docs-img/duik/icons/options.svg) **附加面板**。  
    ![](/docs-img/duik/automation/walkcycle-options.png)
3. **把图层分配到**它们对应的肢体。吸管会设置合成中当前选中的图层。  
    1. 点击 ![](/docs-img/duik/icons/walk_cycle.svg) ***行走 / 奔跑循环***按钮。
    2. Duik 会尝试把控制器的属性连接到行走和奔跑循环，但如果你使用的是自定义绑定，它可能无法全部找到，这种情况下，请阅读下面的效果说明，看看如何手动连接它们。

行走 / 奔跑循环可以在合成中创建的那个行走 / 奔跑循环控制器的效果中调整。

<Callout type="success">
    所有控制器仍然可以制作动画，所以你可以添加自己的关键帧，按你的喜好调整动画或制作任何其他动画。随意移动控制器来调整角色的姿势。
</Callout>

<Callout type="warning">
    程序化的行走 / 奔跑循环使用正向动力学（*FK*)[*](../../misc/glossary)来制作手臂动画，因此会停用反向动力学（*IK*)[*](../../misc/glossary)。手臂控制器的位置不再控制它们，因为动画是在[独立 FK 控制](../constraints/kinematics)[^ik]的角度上制作的。
</Callout>

<Callout type="warning">
    如果你想制作手臂动画或调整手臂，你可以调整控制器效果中独立 FK 控制的数值，或者重新启用 IK，但这会停用手臂上的程序化动画。你可以为 IK 和 FK 之间的切换制作动画，Duik 在[动画](../animation)面板中提供了一个[IK/FK 切换](../animation/tools/ik-fk-switch)工具来简化这一过程。
</Callout>

<Callout type="warning">
    确保左右肢体已被正确标记[^tags]，或在设置行走 / 奔跑循环之前修正标记，以便它正确识别两侧。
</Callout>

## 效果

![](/docs-img/duik/automation/walkcycle-effect.png)

- 使用前三个数值来开始和停止循环：  
    - **整体运动**控制行走和奔跑两个循环。
    - **行走**和**奔跑**数值控制两个循环；你可以通过交叉淡化这些数值，轻松制作从一个到另一个的过渡动画。

- **主要参数**是用于全局自定义和个性化动画的通用设置。
- 你可以使用**独立肢体调整**来进一步自定义循环。
- **高级参数**可以用于在更低的层面调整循环。
- 效果底部暴露了一些**有用的数据**。

### 主要参数

![](/docs-img/duik/automation/walkcycle-main.png)

你可以用一些任意数值来设置主要角色特征（身高、能量……）。这些数值需要相对于角色行走和奔跑进行调整，是主观的。改变它们会给人一种身高、能量、柔软度的*感觉*……

***柔度***控制肢体的拖拽和重叠动画[*](../../misc/glossary)。

#### 行走和奔跑循环

对于两个循环，你都可以调整角色移动的速度。这**不会改变步伐的速度（频率），而是改变其幅度**，就像现实生活一样：一个特定的角色大致总是保持相同的步伐频率，但通过改变步伐的幅度来改变行走或奔跑的速度。  
甚至奔跑循环和行走循环的频率也是相似的。话虽如此，当你在制作从行走循环到奔跑循环的过渡动画时，如果你觉得奔跑循环应该再快一点，不要犹豫，在*高级参数*部分动画化步伐频率。

有两种行走循环类型：`Realistic（写实）`和`Dancing（舞蹈）`。在 `Dancing` 模式下，身体每步有两次弹跳，就像米老鼠一样。

### 独立肢体调整

![](/docs-img/duik/automation/walkcycle-limbs.png)

对于每个肢体，你都可以单独微调动画的每一个部分！标记为***摆动***的属性控制相应部分的旋转，而***柔度***通常控制各部分的拖拽和重叠动画[*](../../misc/glossary)。

### 高级参数

![](/docs-img/duik/automation/walkcycle-advanced.png)

你可以使用***时间偏移***在时间上偏移循环；例如在使用四足技巧时很有用：给前腿应用一个与后腿相同的行走循环，但偏移 `± 20 %`。

使用***步伐幅度***和***频率***可以覆盖所有其他设置并直接控制它们。

### 有用的数据

![](/docs-img/duik/automation/walkcycle-data.png)

在***动画数据***部分暴露的数值就是实际动画。使用自定义的非 Duik 绑定设置行走 / 奔跑循环时，你可以用表达式取色器（pickwhip）指向这些数值，把动画应用到特定属性（只需在取色器生成的表达式末尾加上 `+ value;`）。手臂动画使用 FK，你需要把它们连接到角度属性。脚部动画使用 IK，把它们连接到位置属性。

***腿高***参数应该已由 Duik 自动设置，但对于自定义绑定或特殊角色，你可能需要调整它，以便循环被正确计算。它是从脚踝到髋部的直腿长度，以像素为单位。

最后，***计算***部分暴露了一些有用的数值，可以用在你自己的表达式中，例如用于把其他部分同步到循环动画。

有一个数值尤其有用：***循环时长***，它可以用秒或帧为单位。要渲染完美的循环，你可以把工作区或合成长度设为此值。
