# <img src="/docs-img/duik/icons/looper.svg" style={{width: '1em'}}/> Looper

*Looper* 实际上是自动化面板中[插值器](../animation/tools/interpolator)的一个预设，用来取代旧版 Duik 中的 *Looper*。

![](/docs-img/illustration/Optical_Toy_Phenakistiscope_Disc_with_Cats_and_Donkey_ca._1830_(CH_18607981).png)  
*光学玩具，猫与驴 Phenakistiscope 圆盘，  
约 1830 年  
公有领域。*

1. **选择**属性。
2. 点击 ![](/docs-img/duik/icons/looper.svg) ***Looper*** 按钮

所有插值都被停用，只保留外推，并设置为 *Cycle（循环）* 作为进入和退出外推。

![](/docs-img/duik/automation/looper-effect.png)

▷ 阅读*[动画](../animation) / 工具 / [插值器](../animation/tools/interpolator)* 以了解更多信息。
