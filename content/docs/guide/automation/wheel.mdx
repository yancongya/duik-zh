*Wheel* 会根据图层的平移来自动化图层的旋转[^formula]。

![](/docs-img/illustration/Design_for_Four_Wheel_Dog_Cart,_no._3928_MET_DP882482.jpg)

Brewster & Co.，Herman Stahmer，1884

1. **选择**图层。
2. 点击 ![](/docs-img/duik/icons/wheel.svg) ***Wheel*** 按钮

## 效果

Wheel 可以在图层的效果中调整。

![](/docs-img/duik/automation/wheel-effect.png)

***半径***由 Duik 自动设置，但在某些特殊情况下，Duik 可能无法准确测量它。这种情况下，你必须设置正确的数值，轮子才能以正确的速度旋转。

<Callout type="success">
    你可以用[*测量距离*](../constraints/tools/measure)[^measure]工具测量两个图层锚点之间的距离。用一个空对象图层来测量轮子的半径。
</Callout>

如果你需要制作一个在天花板上而不是地板上滚动的轮子动画，请勾选***反向***选项……

根据轮子所遵循的轨迹类型设置***轨迹***。要小心，这会大幅降低性能。

- *水平*只在轮子沿（几乎）水平面滚动时有效。  
    这种情况下，Duik 只使用图层的 X 位置来获取行进距离。这是性能最好的方式，因为只是一个简单的减法。
- *直线*在轮子沿（几乎）直线移动时有效。  
    这种情况下，Duik 把起点和终点之间线段的长度作为行进距离。这比*水平*选项稍慢，但在大多数情况下差异应该察觉不到。
- *曲线*在所有情况下都有效。  
    这是性能最差的方式：对于合成的每一帧，Duik 都会累加上一帧的行进距离；这是一个*累积表达式*。在长合成中，计算可能会非常慢[^slow]。

使用*曲线*模式并且需要运动模糊时，你可以稍微提高*运动模糊精度*数值来修复运动模糊伪影，但要小心，这会让性能大幅下降[^slow2]。

[^formula]: 自动化轮子旋转的公式其实很简单：`distance / radius` 给出以弧度为单位的旋转角度，`(distance / radius) x 180 / π` 给出以度为单位的旋转角度。

[^measure]: 参见[*链接与约束*](../constraints) / 工具 / [*测量距离*](../constraints/tools/measure)。

[^slow]: 因为在 After Effects 中无法用表达式可靠地存储任何数据，Duik 实际上必须在合成的每一帧重新计算所有内容。这意味着对于每一帧，它都需要累加之前所有帧的数值。对于给定合成，需要计算的数值总数是一个[*三角数*](http://en.wikipedia.org/wiki/Triangular_number)，由公式 `(f² + f) / 2` 给出，其中 `f` 是合成的帧数。由于公式中的 `f²`，这个数字会随着合成时长的增加而飞速增长。

[^slow2]: 如上所述，使用像曲线轨迹轮子这样的累积表达式需要计算的数值数量是一个三角数，它会随合成帧数的增加而快速增长。当你改变*运动模糊精度*时，就像把合成的帧数翻倍、翻三倍等（表达式必须对帧进行二次采样）。当设为 `2` 时，需要计算的总数值数量是 `( (2f)² + 2f ) / 2`，这超过了原来的两倍；设为 `3` 时，`( (3f)² + 3f ) / 2` 更糟，以此类推。
