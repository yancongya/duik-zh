# <img src="/docs-img/duik/icons/paint.svg" style={{width: '1em'}}/> Paint rig

使用 *Paint Rig* 来绑定绘画效果中的画笔笔触，并把它们当作单一笔触来调整和制作动画。

![](/docs-img/illustration/KlimtDieJungfrau.jpg)  
*Die Jungfrau，  
Gustav Klimt，1913  
公有领域。*

1. **选择**一些画笔笔触
2. 点击 ![](/docs-img/duik/icons/paint.svg) ***Paint rig*** 按钮

## 效果

使用添加到图层上的效果，一次性调整和制作所有画笔笔触的动画。

![](/docs-img/duik/automation/paint-rig-effect.png)

***开始***、***结束***、***颜色***和***直径***参数的工作方式，与单独笔触中相同的参数一样，但会控制所有笔触，仿佛它们是单一笔触。

***直径***和***颜色***被分成两个参数，以便能从头一个笔触插值到最后一个笔触，就像通过所有笔触的一条斜坡。  
你可以在***插值***部分改变这条斜坡的工作方式。

笔触的顺序可以随时通过在图层堆叠中重新排列来更改。
