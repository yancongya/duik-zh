# ![](/docs-img/duik/icons/tag.svg) Tag controllers

Sometimes, you may want to use custom layers as controllers (for example, if you designed it yourself, or want to use any existing layer as a controller).  
In this case, you can use this tag tool on these layers so Duik can recognize them as controllers when using other controller tools, like [*Extract controllers*](../extract)&nbsp;[^1] or include them in the [Auto-rig](../../bones/autorig)&nbsp;[^2].

Duik will add a new layer marker on the first frame of the layer, named *Controller*.

[^1]: *cf.* *[Controllers](..) / [Extract Controllers](../extract)*.

[^2]: *cf.* *[Bones and Auto-Rig](../../bones) / [Auto-Rig](../../bones/autorig)*.
