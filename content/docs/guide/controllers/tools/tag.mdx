# <img src="/docs-img/duik/icons/tag.svg" style={{width: '1em'}}/> 控制器标记

有时你可能想使用自定义图层作为控制器（例如，你自己设计的图层，或想把任何现有图层用作控制器）。  
这种情况下，你可以对这些图层使用这个标记工具，让 Duik 在使用其他控制器工具（如[*提取控制器*](../extract)[^1]）或将其纳入[自动绑定](../../bones/autorig)[^2]时，能识别它们为控制器。

Duik 会在图层的首帧添加一个名为 *Controller（控制器）* 的新图层标记。

[^1]: 参见[*控制器*](../index) / [*提取控制器*](../extract)。

[^2]: 参见[*骨骼与自动绑定*](../../bones) / [*自动绑定*](../../bones/autorig)。
