# <img src="/docs-img/duik/icons/settings.svg" style={{width: '1em'}}/> 控制器设置

![](/docs-img/duik/controllers/settings.png)

Duik 中有四种不同的控制器创建模式，可以在面板顶部选择。

![](/docs-img/duik/controllers/types.png)

***![](/docs-img/duik/icons/ae_null.svg) AE 空对象***和***![](/docs-img/duik/icons/controller_raster.svg) 栅格图层***性能最好[^1]，但***![](/docs-img/duik/icons/controller.svg) ![](/docs-img/duik/icons/controller_draft.svg) 形状图层***更容易自定义，并包含动态参考与引导。

默认情况下，当控制器是空对象时，其缩放是被锁定的。这是可选的，可以在此面板中更改。

你可以使用其他控制器设置来更改选中控制器的外观。*![](/docs-img/duik/icons/eye_dropper.svg) 选取选中图层*按钮会从选中的控制器中提取所有数值，以便轻松将相同设置应用到其他控制器。

[^1]: 阅读[*高级 / 性能*](../../../advanced/performance)一节，了解更多关于在 After Effects 中使用 Duik 提升性能的技巧。
