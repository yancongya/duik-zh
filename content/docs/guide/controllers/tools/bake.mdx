# ![](/docs-img/duik/icons/bake.svg) Bake controllers

Duik controllers may be standard After Effects shape layers, with a bunch of expressions and a simple effect to control them. The controller appearance is controlled by this effect and expressions, and this reduces the performance, to the point it can be a big issue in complex projects.

*Baking*[*](../../../misc/glossary) the selected controllers removes all these expressions (and deactivates any dynamic display) to improve the performance.

<Callout type="success">
    Hidden controllers, even if they're not baked, should not have a big impact on performance.
</Callout>

<Callout type="info">
    The [*Extract controllers*](../extract)&nbsp;[^1] tool automatically bakes extracted controllers. This can optionally be changed in the *Extract controllers* settings though.
</Callout>

▷ Read the [*Advanced / Performance*](../../../advanced/performance) section for more tips about how to improve performance in After Effects and using Duik.

[^1]: *cf. [Controllers](..) / [Extract Controllers](../extract)*
