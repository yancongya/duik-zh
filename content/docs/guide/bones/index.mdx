# <img src="/docs-img/duik/icons/bones.svg" style={{width: '1em'}}/> 骨骼

![](/docs-img/duik/bones/bones_demo.gif)

骨骼是 Duik 绑定流程的核心，角色和道具都一样。它们是 After Effects 形状图层，用来驱动美术图层。不在美术图层上直接操作，而是在骨骼上操作，美术图层就不会带任何表达式。这样即使已经完成绑定，也能轻松修改或替换美术素材、把现有绑定复用到多个角色，并且帮助 Duik 的[自动绑定](autorig)知道该如何根据你的角色与肢体类型构建最佳绑定。

![](/docs-img/duik/bones/bones_example.png)

骨骼还带有包络（envelop），作为帮你为剪纸角色设计精确关节的参考；还有面条骨（Noodle），用来快速做出柔软、可弯曲、曲线平滑的肢体，就像软橡胶一样。柔软只会让世界更美好，不是吗？

## 骨骼面板与工具

![](/docs-img/duik/bones/bones_panel.png)

骨骼面板主要由工具栏和若干分类组成，用于创建预设或自定义骨架，之后再用自动绑定功能来绑定。

你可以在顶部字段设置*角色名称（Character Name）*，自动为合成中所有新骨骼加上名称，轻松保持条理。

![](/docs-img/duik/bones/toolbar.png)

骨骼面板顶部的工具栏可以快速访问若干次要但有用的工具。
