# 面条骨（Noodles）

<Video src="https://rxlaboratory.org/wp-content/uploads/rx-videos/Duik17_C05_Noodles__EN_720.mp4" caption="本视频是 [__Duik Ángela 官方完整视频课程__](https://rxlaboratory.org/product/the-official-comprehensive-video-course-about-duik-angela/) 的一部分" />

和包络有点像，面条骨是添加在骨骼图层中的内容，可以用来快速设计矢量肢体或角色。它会画出一条穿过肢体所有关节的平滑形状，形成一种卡通、平滑、橡胶般的肢体。

<Callout type="info">
    面条骨仅在*完整骨骼（Full bones）*模式下可用。详见[*骨骼与自动绑定 / 工具 / 设置*](tools/settings)。
</Callout>

![](/docs-img/duik/bones/noodles.png)

面条骨可以通过每根骨骼图层上的效果来定制，启用或停用该效果即可开启或关闭它。

![](/docs-img/duik/bones/noodle_effect.png)

在这里可以调整它们的大小和外观。

使用 *Curve parameters（曲线参数）*一节可以调整它们在骨骼根部或末端的弯曲方式；默认情况下，面条骨会设置为穿过肢体所有关节的最平滑形状。

<Callout type="success">
    要让某个关节成为尖角而不是平滑曲线，把该关节前一根骨骼的 *End curve length（末端曲线长度）*设为 `0 %`，并把关节后一根骨骼的 *Root curve length（根部曲线长度）*也设为 `0 %`。
</Callout>

与包络一样，只需修改和添加骨骼形状图层中的内容，就能进一步定制这些面条骨。

![](/docs-img/duik/bones/noodle_content.png)
