# <img src="/docs-img/duik/icons/select.svg" style={{width: '1em'}}/> 选择骨骼

点击此按钮可快速选择当前合成中的所有骨骼。

<Callout type="info">
    Duik 通过图层上的标记（默认在合成第一帧）来识别哪些图层是骨骼。你可以通过删除该标记来轻松排除骨骼，或使用[图层管理器](../../tools/layers)[^1]——用它还可以把其它图层标记为骨骼。
</Callout>

[^1]: 参见[*工具 / 图层管理器*](../../tools/layers)。
