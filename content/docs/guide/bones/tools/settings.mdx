# <img src="/docs-img/duik/icons/settings.svg" style={{width: '1em'}}/> 骨骼设置

<Video src="https://rxlaboratory.org/wp-content/uploads/rx-videos/Duik17_C03_boneEffect__EN_720.mp4" caption="本视频是 Duik Ángela 官方完整视频课程的一部分" />

![](/docs-img/duik/bones/settings.png)

Duik 中有两种类型的骨骼，可在面板顶部选择。

![](/docs-img/duik/bones/bone_perf.png)

- **完整骨骼（Full bones）**（默认）：带有包络和面条骨，以及控制外观的所有选项。它们显示为关节之间的连线。
- **轻量骨骼（Light bones）**：更简单的骨骼，没有包络或面条骨，关节处显示为圆点。它们的最大优势是性能：对渲染和表达式求值的影响极小。如果你不需要花哨的包络或面条骨，这是大型项目的最佳选择[^1]。

![](/docs-img/duik/bones/full_light_00000.png)  
*完整骨骼 vs. 轻量骨骼*

除了外观和包络/骨骼的存在与否，两种骨骼类型功能完全相同，与自动绑定的工作方式也一样。

你可以使用其它骨骼设置来更改所选骨骼的外观。*<img src="/docs-img/duik/icons/eye_dropper.svg" style={{width: '1em'}}/> 吸取所选图层*按钮会从所选骨骼吸取所有值，方便将相同设置快速应用到其它骨骼。

[^1]: 有关提升 After Effects 和 Duik 性能的更多技巧，请阅读[*高级 / 性能*](../../../advanced/performance)一节。
