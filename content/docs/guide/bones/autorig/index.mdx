# <img src="/docs-img/duik/icons/autorig.svg" style={{width: '1em'}}/> 自动绑定

<Video src="https://rxlaboratory.org/wp-content/uploads/rx-videos/Duik17_E01_Autorig__EN_720.mp4" caption="本视频是 [__Duik Ángela 官方完整视频课程__](https://rxlaboratory.org/product/the-official-comprehensive-video-course-about-duik-angela/) 的一部分" />

Duik Ángela 的自动绑定是一个灵活而智能的工具，能适应许多不同场景，是 Duik 绑定流程的基石。整个流程可以概括为：

1. 创建骨骼
2. 自动绑定
3. 动画

作为智能工具，它会根据你选中的图层猜测你的意图：既能添加「简单」的 IK，也能一键绑定完整角色。

<Callout type="info">
    *自动绑定*是一个不断进化的工具。在 Duik 的每个未来版本中，它都会越来越好，覆盖更多不同场景。
</Callout>

## 使用自动绑定

1. 在合成中选择若干图层
2. 点击自动绑定按钮。
    - **如果选择中包含骨骼**：
        - 如果是预设骨架（手臂、腿、脊柱、尾巴……），自动绑定会为你绑定一切，之后即可直接开始动画。
        - 如果是自定义骨架，自动绑定会添加 [IK](../../constraints/kinematics)[^1] 来绑定它们，根据图层的数量、位置以及自动绑定设置决定哪种 IK 最合适。
    - **如果选择中包含控制器图层**：  
    自动绑定会在可能时按位置直接使用它们，而不是新建控制器。这是使用你自定义控制器的简便方法（只需确保它们已[打标签](../../controllers/tools/tag)）[^2]。
    - **如果选择的只是普通图层**，自动绑定会添加 IK 来绑定，根据父子关系和锚点位置猜测绑定方式。如果图层尚未建立父子链接，自动绑定也能自动链接；但这种情况下最好按正确顺序选择图层：从肢体末端到根部（从手到肩，或从脚到髋……）。

## 控制器

与 Duik 旧版本不同，Duik Bassel 的自动绑定能为绑定所选图层创建任何所需的控制器，你不必先自己创建它们。

话虽如此，如果你想添加并使用某个特定控制器，只需在运行自动绑定前把它包含在图层选择中，它会被自动检测并使用。例如想用同一个控制器控制两个不同的 IK 时，这特别有用。

<Callout type="success">
    运行自动绑定后，记得查看控制器的效果！根据绑定的内容，那里可能有很多选项。
</Callout>

## 自动绑定选项

<Video src="https://rxlaboratory.org/wp-content/uploads/rx-videos/Duik17_E02_RigOptions__EN_720.mp4" caption="本视频是 [__Duik Ángela 官方完整视频课程__](https://rxlaboratory.org/product/the-official-comprehensive-video-course-about-duik-angela/) 的一部分" />

![](/docs-img/duik/bones/autorig_options.png)

绑定少于三个图层时，自动绑定总知道该怎么做——它能创建同时用 FK 和 IK 动画的控制器；但图层更多时，你可以在自动绑定选项中设置偏好行为。

三根骨骼时可以使用以下方法之一：

- ***1+2 层 IK***：在根部创建单层 IK，在肢体其余两段创建两层 IK，两者由同一控制器控制。例如这是绑定节肢动物腿的默认方式。
- ***2+1 层 IK***：在肢体前两段创建两层 IK，用单层 IK 控制最后一段，两者由同一控制器控制。
- ***FK***：创建 FK 控制器，带有自动重叠动画选项。
- ***Bézier IK***：由 Bézier 函数控制的 IK，类似 After Effects 的 Bézier 路径；例如做尾巴或脊柱需要平滑曲线时尤其有用。
- ***Bézier FK***：把 Bézier IK 与 FK 控制结合，可以通过两端控制器的旋转属性来动画 IK。

对于由三根以上骨骼构成的长链、尾巴和发束，也可以设置你的偏好，此时可选项仅限于：*FK*、*Bézier IK*、*Bézier FK*。

▷ 有关这些选项的详情，请阅读[*约束 / 运动学*](../../constraints/kinematics)一节。

如果**勾选 *Create a root controller（创建根控制器）***，自动绑定会**添加一个总控制器**，可一次性平移和旋转整个绑定。

使用**烘焙选项**可以在绑定前自动[烘焙](../tools/bake)[^3]骨骼；这对**提升绑定性能**很重要。它会在绑定时「冻结」骨骼的当前状态——之后你应该不再需要改变它们的外观。

## 所有动物与肢体类型

Duik 几乎能为所有动物和肢体类型创建骨架，自动绑定也能自动绑定它们。

尽管肢体类型按不同动物类别划分，但你可以任意组合来自不同分类的肢体。这些分类可以看作根据角色运动方式绑定和控制肢体的不同方式。这样你可以创建并绑定任何角色，从混种生物到机器人。

- [![](/docs-img/duik/icons/arm.svg) ![](/docs-img/duik/icons/leg.svg) **手臂与腿**](leg)
- [![](/docs-img/duik/icons/spine.svg) **脊柱**](spine)
- [![](/docs-img/duik/icons/tail.svg) ![](/docs-img/duik/icons/hair_strand.svg) **尾巴与毛发**](tail)
- [![](/docs-img/duik/icons/wing.svg) **翅膀**](wing)
- [![](/docs-img/duik/icons/fin.svg) **鳍**](fin)

</Callout>
