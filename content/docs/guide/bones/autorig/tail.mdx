在 Duik 中，尾巴、毛发以及挂在角色身上的任何东西（如围巾或布料）都可以用尾巴或毛发骨架来绑定。

毛发和尾巴绑定之间的唯一区别是：毛发绑定不会从其附着的肢体继承旋转；这有助于保持毛发（或布料、围巾……）即使头部或身体旋转时也保持垂直下垂。

![](/docs-img/duik/bones/tails_fk_00000.png)  
*使用 FK 控制器绑定的尾巴*

默认情况下，毛发和尾巴使用 [FK 控制器](../../constraints/kinematics)绑定；这意味着它们由肢体根部的单个控制器控制，可以动画旋转，控制器效果中有很多选项[^1]。

虽然大多数情况下用 FK 动画这些肢体容易得多，但在非常特定的情况下你可能需要 IK（例如狗的尾巴被门夹住了。哎哟！）。这种情况下，可以在自动绑定的设置中切换*长链绑定（Long Chain rig）*选项[^2]。

![](/docs-img/duik/bones/autorig_options.png)

这样尾巴可以用 *Bézier IK* 或 *Bézier FK* 绑定。此时会添加三个控制器：尾巴末端的主控制器（用于动画位置），以及另外两个用于更好控制尾巴曲率的控制器[^1]。

![](/docs-img/duik/bones/tails_ik_00000.png)  
*使用 Bézier IK 控制器绑定的尾巴*

[^1]: 有关 IK 和 FK 控制器的详情，请阅读[*约束 / 运动学*](../../constraints/kinematics)一节。

[^2]: 有关自动绑定选项的更多信息，请阅读[*骨骼与自动绑定 / 自动绑定 / 简介*](index#自动绑定选项)一节。
