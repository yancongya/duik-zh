# <img src="/docs-img/duik/icons/oco.svg" style={{width: '1em'}}/> OCO 与元绑定

![](/docs-img/illustration/oco-angela.gif)

*OCO* 是 ***Open Cut-Out 格式***：由 RxLab. 开发，用于导出、共享和导入专用于切片动画的已绑定角色——就像在 After Effects 以及 Blender 等许多其他软件里做的那样。

随着 OCO 的支持，Duik 现在还内置了大量元绑定（Meta-rigs）：预定义好的骨架，借助万能的 Duik [自动绑定](../bones/autorig)，点几下就能给整个角色绑定。

![](/docs-img/duik/oco/oco_panel.png)

## 元绑定库

<Video src="https://rxlaboratory.org/wp-content/uploads/rx-videos/Duik17_C08_OCO__EN_720.mp4" caption="本视频是 Duik Ángela 官方完整视频课程的一部分" />

Duik 里的 OCO 面板是一个**元绑定库**，帮你一键为各种动物创建骨架。

这些元绑定按动物类别分门别类。

每个元绑定都经过精心制作，肢体比例逼真，关节位置最适合 2D 切片动画。也就是说，它们既可用来绑定已有角色，也可作为设计新角色的参考。

由于遵循 OCO 标准，Duik 的[自动绑定](../bones/autorig)能一键给用这些元绑定创建的骨架绑定好，并提供所需的全部控制器，让动画既简单又非常细致。

![](/docs-img/illustration/man.png)
![](/docs-img/illustration/raptor.png)

### 创建新骨架

要从 OCO 元绑定创建骨架，只需在库里找到它，双击该项，或点击 ![](/docs-img/duik/icons/check.svg) 应用按钮。

可以用面板顶部的搜索框筛选类别和元绑定。

要自动给新角色命名，可以在面板顶部的角色名称框里设定名字，创建骨架时就会使用这个名字。

<Callout type="info">
    创建出的骨架使用 [Duik 骨骼](../bones)，所有骨骼选项和功能都可用于进一步自定义[^1]。
</Callout>

![](/docs-img/illustration/rabbit_armature.png)

### 创建选项

如果 `[Shift] + [Click]` ![](/docs-img/duik/icons/check.svg) 应用按钮，就可以设置几个骨骼创建选项。

![](/docs-img/duik/oco/creation_options.png)

- 可以更改要创建的骨骼**类型**：
    - *完整骨骼（Full Bones）*：带[包络](../bones/envelops)和[面条骨](../bones/noodles)[^1]的骨骼——如果你打算用上这些骨骼功能。
    - *轻量骨骼（Light Bones）*：更简单、性能更好，但没有包络、面条骨及其他高级功能。
- 默认**显示骨骼包络**。比如把元绑定当作设计角色的参考时就用这个。
- 默认**显示骨骼面条骨**。可以把元绑定作为设计简单矢量角色的基础。
- 选中***创建新合成（Create new composition）***选项，就会在单独的合成里创建新骨架。

### 扩展库

可以把自己的自定义 OCO 元绑定加入库，来源可以是任何包含 Duik 骨骼的合成。

用面板右下角的按钮管理库内容。

![](/docs-img/duik/oco/oco_lib_buttons.png)

Duik 会收集当前合成中骨骼的所有信息，导出为一个新的 OCO 文件存入库，供以后使用。

![](/docs-img/duik/oco/create_metarig.png)

创建元绑定时，可以附带一个图标，应为小 PNG 文件。

设定角色的大致高度（从最低骨骼到最高骨骼），这样在同一场景里创建多个角色时，就能自动让它们大致处于正确尺寸。这个高度以厘米为单位，与分辨率无关。

### OCO 文件

这个库其实就是一个包含 OCO 文件的文件夹结构，默认位于你的 `Documents` 文件夹。用 ![](/docs-img/duik/icons/folder.svg) 文件夹按钮可以快速打开它；`[Alt] + [Click]` 则可以设定一个新文件夹作为库。这时必须选择（或新建）一个 `OCO.config` 文件，它会保存你的全部 OCO 设置，并在所有使用 OCO 且共用同一配置文件的应用之间共享。

<Callout type="success">
    你可以分享这个库（直接把文件发出去就行），甚至用任何同步服务或应用跨设备同步，比如 [*Syncthing*](https://syncthing.net/)[^2]、*Dropbox*、*OneDrive* 等。
</Callout>

<Callout type="info">
    如果你觉得自己全新的 OCO 元绑定够棒，值得官方收录进 Duik，就友好地发消息告诉我们，地址 [contact.rxlab.info](http://contact.rxlab.info)！
</Callout>
