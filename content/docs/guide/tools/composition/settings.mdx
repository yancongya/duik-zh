# <img src="/docs-img/duik/icons/composition_settings.svg" style={{width: '1em'}}/> 合成设置

<Video src="https://rxlaboratory.org/wp-content/uploads/rx-videos/Duik17_O01_CompTools__EN_720.mp4" caption="本视频是 Duik Ángela 官方完整视频课程的一部分" />

用这个面板可以同时修改多个合成的参数；它还能自动调整所有嵌套预合成的参数，以及它们内部图层的持续时间。

![](/docs-img/duik/tools/comp-settings.png)

1. **勾选你想修改的设置旁边的复选框**
2. **设置要应用的数值**
3. 点击 ![](/docs-img/duik/icons/composition_settings.svg)***合成设置***按钮。

<Callout type="info">
    修改合成持续时间时，所有与合成同时结束的图层（不是在结束前被截断的图层），如果条件允许，其持续时间也会自动更新（例如静态图片、纯色层、形状、时长足够的素材等）。
</Callout>
