# <img src="/docs-img/duik/icons/tools.svg" style={{width: '1em'}}/> 通用工具

![](/docs-img/illustration/Cinematograph_Lumiere_advertisement_1895.jpg)  
*巴黎宣传卢米埃尔兄弟活动电影机的海报，Henri Brispot，1895 年，公有领域。*

这个 <img src="/docs-img/duik/icons/tools.svg" style={{width: '1em'}}/>[^communist] 工具面板汇集了各种零散工具——它们未必与绑定和动画直接相关，却经常派得上用场。

[^communist]: 由于这枚图标收到了一些（非常）负面的批评（甚至辱骂），这里做个说明，或许能安抚被它冒犯到的人。

    首先，这枚图标只是一个梗：作为 Duik 的开发者，我身边的朋友、以及我遇到的几乎所有人，一直都说我是共产党员。眼尖的读者会注意到，这枚图标其实是锤子与镰刀共产主义符号的镜像翻转版，并非原样照搬。

    我确实相信阶级斗争是真实存在的，资本主义和重商主义终将终结。说到底，这也是 Duik 免费开放的原因之一！而且为此我收到的感谢远多于辱骂，这让我很暖心。

    但更重要的是，没有理由为此感到被冒犯。有人把 Duik 里的锤子镰刀图标比作纳粹使用的卐字旗，但两者完全不可类比；是无知让这些人把锤子镰刀与斯大林、斯大林主义划上等号，也是无知让他们把斯大林主义和共产主义混为一谈。因此，使用锤子与镰刀这个共产主义符号，绝不等于支持斯大林主义，甚至不等于支持列宁主义。

    斯大林主义，又称马克思列宁主义，实际上是国家资本主义；这套学说与真正的马克思主义和共产主义相去甚远——后者在斯大林于苏俄掌权之前就已存在了近一个世纪，并在苏联解体后继续存在。我认为，是资本主义的宣传在人们的教育中反复灌输“斯大林主义和苏联就是共产主义，因此几乎和纳粹主义一样坏”的观念。遗憾的是，事实远非如此。我再怎么强调了解共产主义和无政府主义真面目的重要性都不为过。

    回到符号本身。锤子与镰刀虽在 1924 年才被俄罗斯苏维埃联邦社会主义共和国采用，但早在那之前的 1917 年俄国革命期间就已使用。

    锤子代表产业工人阶级，镰刀代表农业劳动者，二者合而为一，在俄国革命期间用来象征作为整体的工人阶级，再合适不过。它后来成为阶级斗争的恰当符号——而阶级斗争正是卡尔·马克思（共产主义）和米哈伊尔·巴枯宁（无政府主义）哲学的核心信条。是的，遗憾的是，我认为阶级斗争在今天仍然非常现实。

    作为共产主义的符号，它不仅被斯大林使用（歪曲），也被他最坚定的对手使用过：它就镌刻在列夫·托洛茨基位于墨西哥的墓碑上——托洛茨基是斯大林最重要的马克思主义对手之一，1929 年被逐出苏联。
