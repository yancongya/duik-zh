# <img src="/docs-img/duik/icons/composition_settings.svg" style={{width: '1em'}}/> 图层管理器

<Video src="https://rxlaboratory.org/wp-content/uploads/rx-videos/Duik17_O02_LayerTools__EN_720.mp4" caption="本视频是 Duik Ángela 官方完整视频课程的一部分" />

图层管理器用于帮你创建、重命名并标记图层。

Duik 设置的图层标记，实际上是加在图层第一帧上的标记，用于显示图层类型和其他有用信息。它们还包含一些对用户隐藏、但自动绑定等工具所需的额外数据。

![](/docs-img/duik/tools/layer-tools.png)

第一行是用于快速创建各类图层的按钮。

- ![](/docs-img/duik/icons/null.svg) **空对象**。  
    它会创建一个特殊的空对象图层，用形状图层而非纯色层来制作。这样做有两个主要好处：项目面板不会被塞得满满当当、保持整洁；并且在需要时可以渲染这个空对象图层（只需取消勾选*参考图层*选项即可）。
- ![](/docs-img/duik/icons/solid.svg) **纯色层**。  
    与*空对象*按钮类似，它用形状图层加一个简单矩形来创建纯色层。额外的好处是：你可以通过矩形的*大小*属性轻松改变它的尺寸，颜色也可以做动画。
- ![](/docs-img/duik/icons/adjustment.svg) **调整图层**。  
    同样，Duik 用形状图层而非纯色层来创建调整图层。这里的额外好处是：图层的内容可以用作调整图层的 Alpha 通道（即作为效果的蒙版）。
- ![](/docs-img/duik/icons/circle.svg) ![](/docs-img/duik/icons/square.svg) ![](/docs-img/duik/icons/rounded_square.svg) ![](/docs-img/duik/icons/polygon.svg) ![](/docs-img/duik/icons/star.svg) **基本图形**。  
    接下来的几个按钮用于创建基本图形，它们会完美居中放置在合成中，所有变换数值初始化为 `0`（缩放和不透明度为 `100 %`）。
- ![](/docs-img/duik/icons/bone.svg) **Duik [骨骼](../bones)**&nbsp;[^bone]（自定义骨架）。  
- ![](/docs-img/duik/icons/move_rotate.svg) **Duik [控制器](../controllers)**&nbsp;[^ctrl]。  
- ![](/docs-img/duik/icons/zero.svg) **Duik [归零](../constraints/tools/zero)**&nbsp;[^zero]。  
- ![](/docs-img/duik/icons/locator.svg) **Duik [定位器](../constraints/tools/locator)**&nbsp;[^locator]。

[^link]: *参见 [骨骼](../bones) / 工具 / [Link Art（链接图形）](../bones/tools/link-art)*.

[^ctrl]: *参见 [控制器](../controllers)*.

<Callout type="success">
    用 Duik 创建的“形状纯色层”，可以很容易地让它始终保持合成的尺寸——即使合成被缩放，或者被复制粘贴到另一个合成里。只需在矩形的*大小*属性中加入这个表达式：`[thisComp.width, thisComp.height];` 你甚至可以让纯色层的尺寸按合成尺寸的比例缩放，把它乘上一个系数即可：`[thisComp.width, thisComp.height] * 0.5;` 会让纯色层变成合成的一半大小（面积的四分之一）。
</Callout>

![](/docs-img/duik/icons/autorig.svg)***自动重命名与标记***按钮是一个智能工具，它会根据选中图层的原始名称，自动设置图层的组别、侧别、类型和名称。它能识别 `L` 或 `Left` 这类单词、前缀和后缀，以及 `_` 或 `-` 这类分隔符，从而推断出该图层应有的全部属性，然后设置正确的标记，并按照 Duik 命名规范（即 Duik 创建图层时给图层命名的方式）重命名图层。

<Callout type="info">
    这正是 [*Link Art（链接图形）*](../bones/tools/link-art)&nbsp;[^link] 工具在设置为“使用图层名称”时所做的事。
</Callout>

你可以使用面板最后一部分为选中图层设置特定属性，或者用 ![](/docs-img/duik/icons/eye_dropper.svg)*选取选中图层*按钮，把一个图层的属性复制到其他图层。
