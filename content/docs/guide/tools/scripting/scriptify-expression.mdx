# <img src="/docs-img/duik/icons/scriptify_expression.svg" style={{width: '1em'}}/> 脚本化表达式

选中一个带表达式的属性，即可把这个表达式转换成一个字符串，方便地嵌入到 `.jsx` 脚本中。你只需把生成的脚本复制粘贴到自己的脚本里，就能快速使用这个表达式。

脚本化后的表达式大概长这样：

```js
var propertyNameExp = ['// A comment',
	'var someVar = 12;',
	'var result = someVar * thisLayer.effect("some slider")(1).value;',
	'result;'
	].join('\n');
```

在这个例子中，`propertyNameExp` 是一个字符串——也就是表达式本身——可以直接从脚本里应用到任意属性上，像这样：

```js
var prop = app.project.activeItem.layer(1).transform.opacity;
prop.expression = propertyNameExp;
```

当然，这个 `propertyNameExp` 变量实际会以它所提取属性的真实名称来命名。

这个字符串先被组织成一个按行组成的数组，再用换行符连接起来，这样在脚本源码中更易读、易编辑。这是我们迄今找到的、在脚本中嵌入表达式的最佳方式。注意 `join()` 函数足够快，性能上完全不是问题（Duik 对包含数百行的表达式这样处理也毫无压力）。尤其是与 After Effects 实际把表达式应用到某些属性时的缓慢相比，这根本不值一提。
