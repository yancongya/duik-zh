# <img src="/docs-img/duik/icons/script.svg" style={{width: '1em'}}/> 脚本编辑器

脚本编辑器是一个非常简单的文本编辑器，让你可以快速编写或编辑简单脚本，并直接从 After Effects 中运行。  
如果你稍懂一点 After Effects 脚本，它对自动化重复任务非常有用。

![](/docs-img/duik/tools/script-editor.png)

在这个编辑器中，完整的 [Duik API](../../../advanced/api) 已经内置，可以更轻松地用它来自动化任务。

▷ 阅读“高级 / [Duik API](../../../advanced/api)”一节，了解如何用 API 编写自己脚本的更多信息和示例。
