# ![](/docs-img/duik/icons/script.svg) Script Editor

The Script Editor is a very simple text editor to let you quickly write or edit simple scripts and run them right from After Effects.  
This is very useful to automate repetitive tasks if you know a bit of scripting in After Effects.

![](/docs-img/duik/tools/script-editor.png)

From this editor, the complete [Duik API](../../../advanced/api) is already included and can be used to automate tasks even more easily.

▷ Read the Advanced / [Duik API](../../../advanced/api) section for more information and examples about how to use the API to write your own scripts.
