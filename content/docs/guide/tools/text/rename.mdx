# <img src="/docs-img/duik/icons/rename.svg" style={{width: '1em'}}/> 重命名

<Video src="https://rxlaboratory.org/wp-content/uploads/rx-videos/Duik17_O03_TextTools__EN_720.mp4" caption="本视频是 Duik Ángela 官方完整视频课程的一部分" />

用重命名工具，你可以一次性重命名任意数量的图层、木偶图钉或项目项。

如有需要，该工具能在重命名后同步更新表达式。如果不需要这个功能，关闭它可以略微提升性能。

![](/docs-img/duik/tools/rename.png)

<Callout type="success">
    你也可以使用 [*图层管理器*](../layers)&nbsp;[^layers]，按照 Duik 的图层命名规范来管理图层的名称和标记。
</Callout>

[^layers]: *参见 [通用工具](..) / [图层管理器](../layers)*.
