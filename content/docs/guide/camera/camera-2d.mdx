# <img src="/docs-img/duik/icons/2d_camera.svg" style={{width: '1em'}}/> 2D 摄像机

<Video src="https://rxlaboratory.org/wp-content/uploads/rx-videos/Duik17_N03_2DCam__EN_720.mp4" caption="本视频是 Duik Ángela 官方完整视频课程的一部分" />

做 2D 动画时，通常直接让 2D 图层的位置动起来，比搭建 3D 空间、用摄像机来运镜要简单。

2D 摄像机工具会创建虚拟的 2D 多层摄像机，只用 2D 图层[^multiplane]就能轻松做出各种运镜。

[^multiplane]: 这相当于传统动画早期迪士尼多层摄像机（竖直式）或 Fleischer 工作室立体光学摄像机（水平式）的数字版本。

和[摄像机绑定](camera-rig)&nbsp;[^rig]类似，Duik 也给这些 2D 摄像机加上了好用的摄像机行为，可以轻松模拟真实摄像机以及操作它们的方式（手持、肩扛、三脚架等）。

[^rig]: 参见[*摄像机*](index) / [*摄像机绑定*](camera-rig)。

![](/docs-img/illustration/Fleischer_stereoptical_camera_fig1_edit.png)

1. **选中**对应背景平面的图层。  
    这一步可选；如果没有选中任何图层，Duik 会创建一个默认的 2D 摄像机。
2. 点击 ![](/docs-img/duik/icons/2d_camera.svg) ***2D 摄像机*** 按钮。

Duik 会为摄像机创建一个控制器，并为每个背景平面创建一个空对象图层（如果没选中图层，则创建三个空对象图层）。选中的图层会自动成为这些空对象的子级。

![](/docs-img/duik/cameras/2d-camera-layers.png)

## 深度层（Levels）

每个空对象图层控制一个平面，即背景的一层深度。在空对象图层的效果里，你可以用一个简单的滑块调整摄像机的**影响程度**。

顾名思义，*摄像机影响（Camera Influence）*表示摄像机控制器对该空对象图层的影响大小。

在生成或复制出的空对象的效果里可以找到「摄像机影响」。常见做法是把这些空对象看作一个个平面，或者说一层层「深度」。

- `0` 表示这一层完全不随摄像机移动。
- `100` 表示这一层与摄像机以完全相同的速度移动。
- `> 100` 表示这一层比摄像机「更近」，移动得更快。
- `< 0` 负值会让这一层朝与摄像机相反的方向移动；这模拟摄像机绕场景中某个中点旋转，那个中点就是 `0` 层。

<Callout type="success">
    假设我们想营造三维空间的错觉，让画面焦点落在中景（*mg*）物体上。你有一个前景（*fg*）图层、一个 *mg* 图层和一个背景（*bg*）图层。把 *mg* 图层父子关系到「深度层 2」（它是主体），把 *bg* 父子关系到「深度层 1」，把 *fg* 父子关系到「深度层 3」。然后把「深度层 1」（*bg*）的摄像机影响设为小于 `100` 的数值（默认 `50 %`），把「深度层 3」（*fg*）的摄像机影响设为大于 100（默认 `150 %`）。这样一来，当你操作控制器时，背景移动速度是 *mg* 的 `50 %`，前景比 *mg* 多移动 `50 %`，从而产生深度/视差的错觉。
</Callout>

<Callout type="warning">
    Duik 会随 2D 摄像机一起创建一个名为 *Z* 的空对象，忽略它就好，不要修改、复制或移动它。它用于给摄像机控制器提供锚点及其他计算，你不需要手动操作它。
</Callout>

如果需要更多或更少的图层来控制其他深度，可以删除或复制这些空对象深度层，然后把真正的背景图像图层父子关系到这些空对象上。

## 摄像机动画与效果

主摄像机控制器上挂了一个效果，帮你给摄像机动画：它带有漂亮的插值，能让运镜平滑，还有高级行为来模拟真实摄像机。

![](/docs-img/duik/cameras/2d-camera-effect.png)

### 设置

摄像机类型和运动类型的工作方式与 [3D 摄像机绑定](camera-rig)&nbsp;[^rig]类似。

**摄像机类型**改变摄像机的行为。  
**固定（Fixed）**摄像机完全没有随机值，严格跟随动画关键帧。  
其他模式——**手持（Handheld）**、**肩扛（Shoulder）**、**三脚架（Tripod）**、**斯坦尼康（Steadicam）**——会在运动中加入手工调校的细微抖动，逼真模拟操作者手持摄像机的方式。根据摄像机类型不同，位置和旋转各轴的自由程度不同，权重也会变化。Duik 会综合所有这些因素生成完美的运动。该选项还会影响**摄像机抖动**的生成方式：每种类型的抖动都不一样，以求最真实的运动。

**运动类型**改变关键帧的插值[*](../../misc/glossary)和外推[*](../../misc/glossary)。  
为了从关键帧生成平滑真实的摄像机运动，Duik 使用不同的插值和外推算法[*](../../misc/glossary)，你只需设定正在做的运动类型：

- **起步后停止**：镜头开始时静止，然后开始运动，并在镜头结束前停下。
- **起始运动**：镜头开始时静止，开始运动，在开始减速之前镜头就被剪掉。
- **结束运动**：镜头开始时已经在运动，然后减速并停下。
- **Easy-Bézier 插值**：如果你想手动微调插值，这个模式参数很少，却能精细调校。
- **线性插值**：当运动需要非常均匀，且镜头开始时摄像机已在运动、结束时也不停下时使用。
- **无（使用实际关键帧插值）**：关闭 Duik 的插值，改用 After Effects 的关键帧插值。

对所有这些运动类型，你都可以用**缓动 / 加速度（Easing / Acceleration）**属性调整摄像机的加减速。这个属性也可以打关键帧！

*Easy-Bézier* 选项位于效果末尾；它们类似于[插值器](../animation/tools/interpolator)&nbsp;[^interpolator]的 Bézier 模式。

[^interpolator]: 参见[*动画*](../animation) / 工具 / [*插值器*](../animation/tools/interpolator)。

### 摄像机动画

虽然你可以直接给摄像机控制器图层的位置打关键帧，但更好、更省事的做法是只在这个效果里做动画——所有运镜都能在这里打关键帧。

Duik 会区分摄像机会产生视差的平移，和不应产生视差的旋转与缩放[^parallax]。当然，你可以把它们组合起来用。

[^parallax]: 现实中就是这样：在理想情况下，旋转不会改变透视，因此不会产生视差——前提是旋转轴正好位于传感器中心（且传感器无限小）。由于这种理想情况几乎不可能，摄像机摇摄时会有极轻微的视差，这是因为传感器除了旋转之外还发生了一点平移。

- **位置**（带视差）  
    - **左右横移（Track left/right）**：水平平移。
    - **上下升降（Pedestal up/down）**：垂直平移。
    - **推拉（Dolly in/out）**：纵深平移（3D 中不存在的第三个轴，用图层的缩放来模拟）。
- **旋转**（无视差）  
    - **左右摇摄（Pan left/right）**：水平旋转（*yaw* 偏航）。
    - **上下俯仰（Tilt up/down）**：垂直旋转（*pitch*）。
    - **旋转（Roll）**：真正的 2D 旋转。
- **缩放**（无视差）
    - **变焦推拉（Zoom in/out）**：真正的 2D 缩放。这模拟摄像机焦距（zoom）的动画。如果你更喜欢带视差的 *dolly* 推拉，请使用 *dolly in/out* 属性。

### 随机运动与摄像机抖动

![](/docs-img/duik/cameras/2d-camera-effect-random.png)

根据*摄像机类型*，Duik 可能会在关键帧动画之上叠加一些**随机运动**，以模拟对应的类型。

你可以调整这种抖动动画的幅度和频率。

你还可以给摄像机抖动的幅度打关键帧，让它在特定时刻抖动，例如爆炸、地面震动或起风……

<Callout type="success">
    你基本不需要改动频率数值——几乎所有摄像机都适用同一组频率。
</Callout>

和所有其他随机值一样，你可以在效果的高级部分更改**随机种子（seed）**，来测试运动的不同版本（或让多个控制器使用同一个种子，生成相同的运动）。
