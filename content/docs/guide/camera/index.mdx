# <img src="/docs-img/duik/icons/camera.svg" style={{width: '1em'}}/> 摄像机

> 好动画需要好摄像机。摄像机应被视为动画的角色之一，它的动画必须和观众在画面中看到的角色动画一样细致。

正因如此，Duik 也提供了实用的摄像机工具。

![](/docs-img/illustration/Institut_Lumière_-_CINEMATOGRAPHE_Camera.jpg)

## 摄像机面板

![](/docs-img/duik/cameras/camera-panel.png)

顶部工具栏里的工具，是给摄像机动画时可能用到的快捷工具。

第二部分的主要工具用于给 3D 摄像机绑定，或创建 Duik 2D 摄像机。
