# API 中的 Duik 功能

Duik 几乎所有功能都以非常简单的函数形式暴露在 API 中。

由于 Duik 功能众多，它们被归类到*命名空间*（namespace）下，这些命名空间实际上对应 Duik 的各个面板。

当然，所有这些方法都有完整文档；你可以阅读 [`Duik` 命名空间](https://duik.rxlab.io//Duik.html)的参考手册来了解全部方法。

- [**`Duik.Animation`**：动画师工具箱](https://duik.rxlab.io//Duik.Animation.html)（复制/粘贴动画、补间、snapKeys……）
- [**`Duik.Automation`**：懒人动画师工具箱](https://duik.rxlab.io//Duik.Automation.html)（NLA、运动轨迹、抖动、随机、行走循环……）
- [**`Duik.Bone`**：骨骼与骨架相关工具](https://duik.rxlab.io//Duik.Bone.html)（腿、手臂、烘焙……）
- [**`Duik.Camera`**：相机工具箱](https://duik.rxlab.io//Duik.Camera.html)（取景、绑定、twoDCamera……）
- [**`Duik.CmdLib`**：Duik 命令行库](https://duik.rxlab.io//Duik.Camera.html)。这是一个专用命名空间，供 *Duik Command Line* 面板使用。
- [**`Duik.Constraint`**：用于绑定骨骼与图层的约束](https://duik.rxlab.io//Duik.Constraint.html)（twoLayerIK、oneLayerIK、bezierIK、orientation、parentAcrosscomp……）
- [**`Duik.Controller`**：控制器相关工具](https://duik.rxlab.io//Duik.Controller.html)（创建、烘焙……）
- [**`Duik.Layer`**：图层相关工具](https://duik.rxlab.io//Duik.Layer.html)（setLimbName、setCharacterName、select、sanitizeName……）
- [**`Duik.Pin`**：图钉相关工具](https://duik.rxlab.io//Duik.Pin.html)（create、linkPathToLayers、linkPuppetPinsToLayers、addPins……）
- [**`Duik.Rig`**：（自动）绑定工具](https://duik.rxlab.io//Duik.Rig.html)（auto、arm、leg、fin、wing……）
- [**`Duik.Tool`**：杂项工具](https://duik.rxlab.io//Duik.Tool.html)（cropPrecompositions、editExpression……）

## 示例

要运行 *arm*（手臂）自动绑定，只需调用 `Duik` 的 `Rig` 命名空间下的 `arm` 方法：

```js
    // Automatically rig the selected bones as an arm
    Duik.Rig.arm();

    // Or you can pass an array of layers to the rigging methods
    Duik.Rig.leg( someLayers );
```

再举一例，你也可以给选中的属性，或你指定的某些属性，添加抖动效果。

`wiggle` 方法位于 `Duik` 的 `Automation` 命名空间下：

```js
    // Add a Wiggle control with default options to the selected properties
    Duik.Automation.wiggle();

    // Or you can set some parameters
    // 1. Separate dimensions
    // 2. Add one control per property (instead  of a single control for all of them)
    // 3. An array of properties to setup
    Duik.Automation.wiggle( true, true, someProperties );
```
