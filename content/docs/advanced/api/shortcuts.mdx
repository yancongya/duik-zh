# 为 Duik 功能添加键盘快捷键

<Video src="https://rxlaboratory.org/wp-content/uploads/rx-videos/Duik17_B04_Shortcuts__EN_720.mp4" caption="本视频是 Duik Ángela 官方完整视频课程的一部分" />

借助 API，你只需写短短几行代码就能创建[*无头脚本*](headless-scripts)。这些脚本随后可以很方便地在 *After Effects* 中分配键盘快捷键。

以这个脚本为例：

```js
(function(){
    #include "DuAEF_Duik_api.jsxinc"
    DuAEF.init( "Auto-Parent", "1.0.0", "RxLaboratory" );
    DuAEF.enterRunTime();

    // Run the Auto-Parent method
    // See: http://duik.rxlab.io/Duik.Constraint.html#.autoParent
    Duik.Constraint.autoParent();
})();
```

把它保存为名为 `Auto-Parent.jsx` 的文件即可。

## 在 After Effects 中放置脚本

首先，我们要把脚本放到 After Effects 能找到的位置。

把 `Auto-Parent.jsx` 文件复制到：

- Windows：`C:\Program Files\Adobe\Adobe After Effects XXXX\Support Files\Scripts\`
- Mac：`/Applications/Adobe After Effects XXXX/Scripts/`

由于脚本使用了 Duik API，API 也需要复制到同一文件夹。把 `DuAEF_Duik_api.jsxinc` 复制到同一文件夹[^1]。

## 分配快捷键

如果 After Effects 当时是开着的，先重启它，然后进入 `Edit ► Keyboard Shortcuts`（编辑 ► 键盘快捷键）。

![](/docs-img/ae/ae_keyboard_shortcuts.png)

要把 `[Ctrl] + [P]` 分配给这个脚本（举例），先点击键盘示意图上的 `P` 键，看看它当前已分配了什么，确认你确实想替换掉默认设置。

然后在搜索框中输入脚本名找到它，点击它旁边标有 *Shortcut* 那一列的空白处，接着按下你想用的快捷键，就大功告成了！

[^1]:
    把 API 复制到文件夹后，你想加多少个使用它的脚本都行，它们共享同一个文件。不过要注意：如果不同脚本需要不同版本的 API，你可能得重命名 API 文件，把不同版本存放在同一文件夹里，并相应地更新 `#include` 行。
