*Duik* 是一套功能完备的 After Effects 角色绑定与动画工具集。它是一个终端用户工具，以独立面板的形式出现在 After Effects 的界面中。

为了让有一点脚本基础的人能在自己的脚本、自动化、自动绑定等中使用 Duik，*Duik* 还附带了一套易用的 API。不过它对高级开发者也很有用，因为它还包含大量底层方法，以及一套面向 After Effects（更广泛地说，面向 Adobe 应用）的、非常完备的脚本框架。

它用 *[ExtendScript](http://extendscript.docsforadobe.dev/)* 编写，并基于标准的 *[After Effects API](http://ae-scripting.docsforadobe.dev/)*。

如果你从没为 After Effects 写过脚本，可以先学习如何创建高级*[表达式](http://ae-expressions.docsforadobe.dev/)*，因为表达式使用同样的语言，其 API 也与 *[After Effects 脚本 API](http://ae-scripting.docsforadobe.dev/)* 非常接近。学会之后，你就能写出第一批脚本了。
