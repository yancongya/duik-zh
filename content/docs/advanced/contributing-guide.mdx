## 贡献

### 代码

如果你是同行开发者，无论新手还是老手，都欢迎为 Duik 的开发出力。大部分工作在[我们专用的代码仓库](https://github.com/RxLaboratory/Duik)上进行，你可以在 [**source.rxlab.io**](http://source.rxlab.io) 快速找到它。

如果你还不会使用 [*Git*](https://git-scm.com/)，先从上手它开始。并不难。

提交代码改动的常规流程如下：

1. **先克隆仓库**。直接在仓库网页上就能轻松完成。
2. 把你的仓库副本**克隆到本地**电脑上，可以用命令行，也可以用任意 Git 图形界面应用（列表见 [git-scm.com](https://git-scm.com/)）。
3. 然后就可以开始**写代码**了。
4. 定期**提交**（commit）改动，并**推送**（push），命令行或 Git 图形界面均可。
5. 向我们的仓库提交一个**拉取请求**（Pull Request），我们会审查你的改动。同样在仓库网页上就能轻松完成。

如你所见，这个流程很好懂；如果你不熟悉命令行，全程都可以用图形界面完成。

不确定自己在做什么也别担心，别害羞。在代码并入 Duik 之前，我们会审查并修复（或者请你修复）你的代码，并帮你学习。我们尽一切努力让你在每一个与我们接触的地方都感到被接纳、安全。我们都曾是新手 ;)

如果你需要帮助，或者想提交一段代码、一个示例、你自己的脚本，以及任何不适合走上面流程的东西，别犹豫，通过[联系表单：**contact.rxlab.info**](http://contact.rxlab.info) 或[聊天服务器：**chat.rxlab.info**](http://chat.rxlab.info) 联系我们聊一聊！

### 文档

如果你是 Duik 的熟练用户，或者在文档与用户指南中发现了错误和笔误，欢迎直接编辑，或者新建页面！

在线阅读文档时，页面右上角应该有一个 *Edit*（编辑）按钮。点击它就能提交你的改动；我们会审查并尽快让改动上线。编辑后没马上看到变化也别担心，改动需要先被接受，不会自动发布。

文档使用 [*Markdown*](https://en.wikipedia.org/wiki/Markdown)&nbsp;[^md] 语法：源码就是遵循该语法的纯文本文件，*html* 网页由一个叫 [*MkDocs*](https://www.mkdocs.org/) 的工具据此生成。你会发现 Markdown 非常简单易用、上手很快。

[^md]: *参见 [en.wikipedia.org/wiki/Markdown](https://en.wikipedia.org/wiki/Markdown)*

Duik 在线文档的地址是 [**duik.rxlab.guide**](http://duik.rxlab.guide)

### 翻译

我们努力让 Duik 支持尽可能多的语言。开发工具时，它们先用英文编写（因为所有编程语言都用英文关键字，这样更方便）。但我们希望默认语言是[世界语（Esperanto）](https://en.wikipedia.org/wiki/Esperanto)&nbsp;[^esperanto]，因为没有理由英语就该是国际通用语 *la internacia lingvo*。当然现实就是如此，明天也不会改变，但我们想证明它本可以不同。

[^esperanto]: 世界语（Esperanto）是世界上使用最广泛的人造国际辅助语言，创造于 1887 年，旨在成为国际交流通用的第二语言，即"国际语"（la Internacia Lingvo）。*参见 [en.wikipedia.org/wiki/Esperanto](https://en.wikipedia.org/wiki/Esperanto)*

最理想的情况是：任何用户都能用自己选择的语言使用工具。我们注意到，当一个工具被翻译后，它在该新语言使用国的使用率会大幅上升。以下是 Duik 用户最常用的语言：

- （世界语）
- 英语
- 法语
- 西班牙语
- 中文
- 葡萄牙语
- 日语
- 德语
- ……

但任何语言的翻译都受欢迎！

技术上，翻译 Duik 用的是开放的 [PO 文件](https://en.wikipedia.org/wiki/Gettext)。编辑这些翻译，我们使用在线协作平台 [*Crowdin*](https://crowdin.com/profile/duduf)；如果你更喜欢下载文件离线工作，我们也推荐 [*PoEdit*](https://poedit.net/)、[*Virtaal*](https://virtaal.translatehouse.org/) 这类免费应用。这些文件用任意文本编辑器也能轻松编辑。

当你决定帮忙翻译 Duik 时，最好先加入我们的[聊天服务器：**chat.rxlab.info**](http://chat.rxlab.info)，这样我们能帮你，你也能和使用相同或其他语言的译者交流。

#### 通过 *Crowdin*

帮忙翻译工具最简单的方式是在 [Crowdin.com](https://crowdin.com/) 注册一个免费账号，然后开始为你选择的项目贡献。Duik 项目在 [**translate.rxlab.io**](http://translate.rxlab.io)。

如果你想翻译成的语言还没列出，尽管告诉我们，我们马上加上！

#### 通过本地应用

如果你更喜欢用应用翻译工具，得先把翻译文件下载下来编辑。你可以在对应的 [**source.rxlab.io** 仓库](http://source.rxlab.io)或 [**translate.rxlab.io** 的 Crowdin 项目](https://translate.rxlab.io)找到它们。先在平台注册免费账号，再下载文件。完成后把它们发回来即可（发到我们 [chat.rxlab.io 聊天服务器](http://chat.rxlab.io)、作为附件贴到仓库的 issue、或提交一个[拉取请求](http://git.rxlab.io)、或上传到 [Crowdin](https://crowdin.com/profile/duduf)，随你选择！）。
