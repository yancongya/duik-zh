# 参考图控制器约定

视觉参考只约束控制器，不替换已确认的人物。参考图的角色、文字、水印均不进入新素材。

| 控件 | 显示 | 行为 |
| --- | --- | --- |
| handL / handR | 实心红小方块，白色细圈 | 双臂 IK 目标；固定骨长，限制拖拽半径 |
| hairL / hairR | 紫色锥形发骨末端红方块 | 分别控制左右发束的小幅变形 |
| root | 腰部洋红细圆环 | 整体平移 |
| body / head | 洋红同心目标环 | 上身 / 头颈倾斜 |
| smile | 嘴旁小洋红环 | 水平拖动调微笑 |
| direction | 左上洋红水平双箭头 | 头部方向，仍是小幅平面旋转 |
| gaze | 左侧绿色眼形 | 横向视线，纵向闭眼 |
| globalMove | 左下绿色移动图标 | 整体平移 |
| bodyGlobal | 左下洋红小环 | 上身倾斜 |

骨骼采用半透明锥形，画面左侧灰红、右侧灰蓝，发骨紫色；关节是极小圆点。暖浅黄色舞台只服务于参考控制器语言。标签默认隐藏，在悬浮或键盘焦点时出现；可以打开“显示控制器标签”。

风格常量唯一来源为 `assets/webui/rig-controller-overlay.js`。固定外围控制器的位置来自 `project.json.controllers`，骨骼和内部控制器由实际姿态矩阵计算。画面坐标和人物左右的区别写入部件标签。

验收：逐个真实拖动并比较姿态数值和 canvas 像素；连续键盘操作保留焦点；展开/原图模式不残留可拖动控件。参考样式复用不等于截图逐像素复刻，因为用户选定的人物比例不同。
